# 天窗智巡 · 东北低空交通运行中心 V1.2

覆盖 36 个地级行政区的本地模拟运行系统：53 条飞行汽车走廊、108 条城区外卖无人机走廊、连续四维冲突调度与三维推演。跨省仅连接沈阳—长春—哈尔滨。真实城市地图、三维飞行器、气象监测与 AI 研判已整合到统一操作界面。

本轮更新详见 [V1.2 城市三维运行系统说明](docs/CITY_OPERATIONS_V1.2.md)。

**当前交付为源码更新。未上传、未生成新 JAR、未生成前端发布包。**

## 运行更新版

1. 双击 `start.bat`：编译 Java 源码并启动 Python、Java、Vite。三个服务就绪后会自动用系统默认浏览器打开运行中心。
2. 启动窗口会持续驻留并监控服务，不要关闭；运行地址是 **http://127.0.0.1:5180**。8085 是 Java API，8600 是 Python 内部服务。
3. 双击 `stop.bat`：按项目目录、PID和启动时间校验，停止本项目三个进程。启动窗口会显示停止完成，并等待按键后关闭。

源码入口不依赖旧 JAR。`scripts/start.ps1` 是历史发布包启动器，本轮不用；`build.bat` 留作未来构建入口，本轮未执行。

前置环境为 JDK17、Node.js、Python3.13。本机依赖已安装；新机器见 [本地运行说明](docs/local-v1.md)。服务只监听本机，源码启动默认关闭外部推送。

## 使用

- 运行总览：选择36城之一，加载城市道路与立体建筑；可旋转、跟随航班和进入地图专注视图。
- 调度台账：搜索班次、筛选状态，选择班次查看起降轨迹、升降剖面并暂停或恢复未来班次。
- 预警中心：合并同一走廊与原因的事件，直接定位相关班次。
- 气象监测：移动模拟天气与官方历史观测台账分开显示。
- 智能研判：结合当前网络、班次、气象和人工操作证据解释调度结果。
- 操作记录：本地保存人工操作；按时间回看，支持导出当前完整记录。

城市底图需要联网。班次、订单、天气及起降点为模拟数据；部分地区建筑覆盖不完整，楼宇与地形尚未用于实机避障。完整数据范围和限制见 [V1.2 说明](docs/CITY_OPERATIONS_V1.2.md)。
