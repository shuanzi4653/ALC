================================================================
  天窗智巡  ·  云端访问包
================================================================

【包信息】

  目标地址   https://tianchuang.shuanzi.site/
  包版本     2026-10-14
  文件数     4 个（见文末清单）
  运行要求   Windows 10/11，无需安装任何东西，无需管理员权限

【这是什么】

  一个"打开网页就能用"的访问包。整个项目跑在云服务器上：
  页面、数据、操作都在云端。这个文件夹里没有程序、没有数据库、
  也没有任何项目数据 —— 它只负责帮你把浏览器带到云端那个地址。

【怎么用】

  1. 双击本文件夹里的  启动天窗智巡.bat
  2. 会弹出一个黑窗口，自动连接云端（最多重试 3 次）
     - 连得上  -> 自动打开浏览器，进入项目
     - 连不上  -> 黑窗口会写明原因和下一步怎么做
  3. 浏览器会直接进入项目，【不需要登录】。
     第一次打开时，页面会在你的浏览器里生成一个随机的【工作区编号】。
  4. 你的推演、方案和气象通道都记在这个工作区里：
     - 同一个浏览器下次打开，还是同一个工作区，看到的是你自己上次的内容
     - 换设备 / 换浏览器 / 清了浏览器数据 -> 会得到一个新的空工作区
       （这是正常现象，不是数据丢了）
     - 想换一个干净的工作区：点页面右上角的【重置工作区】
       （原工作区的内容不会被删除，只是不再显示）

  启动器默认用【普通窗口】打开。这一点和旧版本不同：旧版本默认用隐私窗口，
  目的是不让浏览器记住登录口令；现在没有口令了，而隐私窗口会在关闭时丢掉
  工作区编号、让每次打开都变成一个空工作区，所以改回普通窗口。

  想让桌面多一个快捷方式：双击  在桌面创建快捷方式.bat  即可。

【关于"工作区"】

  本包不需要账号和口令。为了让你和别人的数据互不干扰，页面会在你的浏览器里
  随机生成一个【工作区编号】。

  * 它不是账号：不用注册、不用输入，也不包含你的任何个人信息。
  * 它存在你的浏览器本地（Cookie + 本地存储），跟着浏览器走，不跟着包走。
  * 同一个浏览器 -> 同一个工作区；换设备 / 换浏览器 / 清数据 -> 新的空工作区。
  * 服务端只按这个编号把数据分开放，不采集你的身份信息。
  * 大家共用同一套实时数据（气象、航班、告警）；分开的只是你自己发起的
    推演、方案和通道选择 —— 所以两边看到的"趋势"一致、"自己做过的事"各自独立。

【连不上怎么办】

  启动器会分两种"连不上"来报，因为这两种原因完全不同：

    现象：连接超时（对方没回应）
      -> 这台云服务器当前不可达（停机 / 维护 / 平台网络问题），
         或者你所在网络限制了对外访问。

    现象：连接被拒绝（端口没人监听）
      -> 云端服务没启动，或入口没挂上。等一分钟再试一次。

  其他常见情形：
    * 你所在网络（校园网 / 公司网 / 公共 WiFi）限制对外访问
      -> 换手机热点再试一次，即可区分。
    * 浏览器提示"证书有问题"
      -> 先确认本机时间/日期是对的；仍报错请把提示截图发给站点提供者。
    * 页面能打开，但内容是空的、也没有之前的方案
      -> 多半是浏览器禁用了 Cookie / 本地存储，或者你清了站点数据；
         换回浏览器默认设置、或用同一个浏览器再打开一次即可。
    * 页面出现了要求输入账号口令的登录页
      -> 本站【不应该】有登录页。这多半是站点配置被改回旧版本了，
         请把该页面截图发给站点提供者。

  说明：本项目的公网入口只有 443（域名 + HTTPS）。
  不要尝试去"放通" 28081 之类的端口 —— 那不是入口，开了也没用。

  如果这个包是别人给你的：把黑窗口整屏截图发给他即可，不用自己排查。

【这个文件夹不会做什么】

  * 不读取、不上传你本机的任何文件
  * 不安装任何东西、不修改系统设置
  * 不启动任何本地服务（没有本地后端、没有本地前端）
  * 不写注册表、不设开机启动项
  * 不访问除上面那个目标地址以外的任何网站
  * 不要求、也不保存任何账号或口令

  它只做两件事：探测云端是否可达，然后打开浏览器。
  （"在桌面创建快捷方式.bat" 额外做一件事：在你桌面放一个快捷方式。
    它只写这一个 .lnk 文件，不碰别的东西。）

【文件清单】

  启动天窗智巡.bat          <- 双击这个
  在桌面创建快捷方式.bat    <- 可选，在桌面放个快捷方式
  launcher.ps1              <- 启动器本体，被上面两个 bat 调用，不用管它
  readme.txt                <- 本说明

  四个文件请保持放在同一个文件夹里。不要只单独拷走某个 bat。
  文件夹可以整个复制到任何位置（U 盘、别的电脑都行），路径不限中文。
  移动或改名文件夹后，之前创建的桌面快捷方式会失效，重新运行一次即可。
