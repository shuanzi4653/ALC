## 0. 一句话

0.10.1 把"标签从大模型换成判据"，但指标衡量的仍然是**复现判据的能力** ——
`macroF1 0.977` 很漂亮，而评委只要问一句"它能预报天气吗"，那张表就塌了。

0.11.1 把这件事做完：**标签换成 3 个机场 7 年的 METAR 实测，输出换成概率，
指标换成气象圈认的那四个（AUC / TS / POD / FAR / Brier），并配三条基线。**
于是"准不准"有了一个能被质疑、能被复算、也能被比下去的答案。

## 1. 换芯：数据 → 标签 → 模型 → 指标

### 1.1 数据（`tools/ml/build_metar_dataset.py`）

| 项 | 读数 | 口径 |
|---|---|---|
| 站点 | ZYTX 沈阳 / ZYCC 长春 / ZYHB 哈尔滨 | Iowa State ASOS archive，`report_type=3` 逐时 METAR |
| 年份 | 2019–2025 | 单次拉取，落 `data/training/metar/series.csv` |
| 行数 | **183 493** 行（三站各约 6.1 万） | 每行 = 一站一小时 |
| 特征缺失率 | `visM` / `windMs` / `tempC` / `dewC` / `qnhHpa` **全 0** | `gustMs` 与 `cloudBaseM` 见下 |

两个字段的"缺失"不是缺测，是**没有发生**：

- `gust`（阵风）**97% 的小时没有值** —— METAR 只在出现阵风时报 `G`。语义是"没有阵风"，
  故用持续风回填并留痕 `gustSource='FALLBACK_WIND'`（OBSERVED 4 712 / FALLBACK 178 781）。
  这条留痕必须随数据一起走，否则"阵风 0"与"没报阵风"会在下游长得一样。
- `skyl1` 大量报 `M`，且常与 `skyc1 in {CLR, SKC, NSC, NCD, CAVOK, M}` 同时出现 ——
  与"晴空"同义，不是缺测。故给 5 000 m 哨兵并记 `cloudSource='CLEAR_SENTINEL'`
  （OBSERVED 55 801 / CLEAR_SENTINEL 127 691）。
- `mslp` 在 `report_type=3` 下**整列不返回**（实测 0/8 736）→ 改用 `alti`（英寸汞柱 ×33.8639）。

### 1.2 标签与切分

三个任务，全部是"未来 1–3 h 内是否发生"，窗口 `t+1..t+3`：

| 任务 | 定义 | 正例率（test） |
|---|---|---|
| `vis` | 能见度 < 1 000 m | 0.71% |
| `vis3k` | 能见度 < 3 000 m | 6.33% |
| `gust` | 阵风 > 10 m/s | 2.12% |

切分**按时间**：train ≤ 2023-12-31 / val 2024 / test ≥ 2025-01-01，区间不相交、不随机打乱。

### 1.3 模型（`tools/ml/train_nowcast.py`）

`RandomForestClassifier(n_estimators=100, max_depth=10, min_samples_leaf=100,
max_features='sqrt', class_weight='balanced_subsample', random_state=42)`，
导出为纯 Python 树 `alc-forest-v1`，运行时只做查表打分（`backend-python/ml/nowcast.py`）。

| 产物 | 体积 |
|---|---|
| `models/ml-v2-vis.json` | 636 538 B |
| `models/ml-v2-vis3k.json` | 1 282 473 B |
| `models/ml-v2-gust.json` | 1 198 906 B |
| 合计 | **3.0 MB** |

导出对照：**202 条，最大偏差 0.0（容差 1e-6）**。
两条使对照成立的细节：① 取**未舍入**概率（`probabilitiesExact`），否则 5e-5 的显示舍入会被读成"导出走样"；
② 输入先压成 `float32` 再比阈值（sklearn 树内部就是 float32），否则阈值边界上会系统性差 1e-4。

### 1.4 指标（工作点阈值在验证集上按 TS 最大化选取）

| 任务 | AUC | 工作点 | TS | POD | FAR | Brier | 提前量中位 |
|---|---|---|---|---|---|---|---|
| `vis3k` | 0.947 | 0.30 | **0.4936** | 0.6741 | 0.3517 | 0.0298 | 60 min |
| `vis` | 0.9528 | 0.23 | **0.2568** | 0.4653 | 0.6357 | 0.006 | 120 min |
| `gust` | 0.9358 | 0.21 | **0.2846** | 0.4460 | 0.5597 | 0.0254 | 60 min |

三条基线（同一 test 集、同一事件定义）：

| 任务 | 本模型 TS | 持续性 | Open-Meteo | 单要素阈值规则 |
|---|---|---|---|---|
| `vis3k` | **0.4936** | 0.4855 | 0.0967 | 0.0337 |
| `vis` | 0.2568 | **0.2683** | 0.0311 | 0.1972 |
| `gust` | **0.2846** | 0.1861 | 0.1804 | 0.1861 |

> **`vis` 那一格输了，而且写在这里。** 低能见度 <1 000 m 的事件率只有 0.71%，
> "沿用当前观测"在这种稀有事件上是极强的对手。本模型的增量在**概率与提前量**，
> 不在命中率 —— 模型卡页把这一格原样印出来，并在结论条里直说"这一项没赢基线"。
> 只报赢的那两格，是最容易被评委一句话拆穿的那种报告。

### 1.5 为什么工作点不是 0.5

isotonic 校准之后概率很少越过 0.5（`vis3k` 的 test 集里 88% 落在 0–0.1 箱）。
固定 0.5 会让 POD 掉、TS 掉。故：**阈值在验证集上按 TS 最大化选**，指标按工作点上报，
同时把 `atThreshold05` 那一组也留在载荷里 —— 读者能自己看出两个口径差多少。

## 2. 概率层（`backend-python/traffic/v2.py`）

七个只读端点，全部**不重算几何、不重算班次**（复用 `traffic.network()` / `traffic.session()`）：

```
GET  /api/traffic/v2/overview                  一句话结论 + 四个带基线的数字
GET  /api/traffic/v2/corridors?limit=&mode=    走廊清单（按 pMax 降序）
GET  /api/traffic/v2/corridor/{id}             走廊剖面：逐 5 km 采样 + 0–6 h 曲线 + 判据清单
GET  /api/traffic/v2/modelcard                 模型卡（指标 / 基线 / 混淆矩阵 / 可靠性 / 失败样本）
GET  /api/traffic/v2/counterfactual?seed&scenario&policy   A/B 重放
GET  /api/traffic/v2/divergences?limit=        分歧台账
POST /api/traffic/v2/decision                  人工裁决落账（空理由 → 422）
```

### 2.1 插值

沿走廊每 **5 km** 采样，反距离加权（**1/d²，最近 3 站**）。
不确定度 `σ = 0.05 + 0.02 × 最近站距(km)`；最近站距 > **250 km** 时 `confidence='LOW'`，
一律降级为"建议人工复核"，**不给"可飞"**。

> **偏离手册 §8.7 一处（留痕）**：手册伪代码里地形修正是"海拔越高、概率越高"，
> 但同一节自己的说明写的是"高海拔空气更清"。按物理意义实现为**更高更清**，
> 并在载荷里给 `terrainCorrection: 'APPLIED' | 'NO_DEM'`。缺 DEM 时不做修正、如实报 `NO_DEM`。

### 2.2 融合（`_fuse`，三段式）

1. 规则一票否决（`rule_level == 2`）→ 永远是 2；
2. 置信度 `|p-0.5|×2 < 0.65` → 保持规则档位，**转人工**；
3. 模型只能升档：`p ≥ 0.8` → 观察（待人工确认）；`p ≥ 0.5` → 注意。

判据钉的是**全网格**（`rule ∈ {0,1,2} × p ∈ 0..1 step 0.05 × conf ∈ 6 档`）：
`fused >= rule` 处处成立 —— 挑点看是测不出"放松"的。

### 2.3 期望损失（`_decision`）

`L(直飞) = p × I`；`L(延误) = 40 + p_delay × I`；`L(绕飞) = 25 + p_alt × I`；`L(取消) = 180`
（`I` 为事故代价，三档只改 `I`：20000 / 10000 / 4000）。

> **偏离手册 §9.2 一处（留痕）**：手册给 `c_cancel = 180`，但 `180 < 25 + 0.83×10000 = 1225`，
> 纯按 argmin 会在 **p > 1.8%** 时一路推出"取消最优"，与手册自己那段示例
> （"绕飞 1225 ✅ 最优"）自相矛盾。根因是成本表里**没有"取消会丢掉整班任务"这一项**。
>
> 修法不是把 180 改成一个大数（那会让"按手册对表"失效），而是把**取消从成本比较里拿出来、
> 变成没有可执行动作时的兜底**：有可用备选走廊 → 取消不入候选；`p < 0.50` → 取消也不入候选。
> 四项损失仍然全部算出来并随载荷返回（`losses` / `eligible` / `excluded`），
> 评委依旧能按手册的算式逐项核对，也能看见"如果只看成本会选取消"。

### 2.4 3–6 h 的模式延伸

`MODEL`（0–3 h，METAR 驱动）与 `MODEL_EXTENSION`（3–6 h，Open-Meteo 逐时值按**历史频率表**映射）
在载荷与图上**都分开**，不合并成一条曲线 —— 合并会让读者以为 6 h 都是模型算的。
频率表分箱若**没有历史样本**，返回 `None` 而不是插值：插出来的数最像真的，但它不是观测频率。

## 3. 界面（手册 §2 / §4 / §10）

### 3.1 五页 IA

顶层从 10 个平铺页签改成 **5 个带编号的入口**，页内一行子视图常驻：

```
① 态势   运行首页 / 运行总览 / 气象监测
② 走廊   走廊剖面 / 民航情报
③ 处置   预警中心 / 智能研判 / 调度台账
④ 检验   模型卡 / 算法机理
⑤ 复盘   反事实对照 / 分歧台账 / 运行日志 / 口径与来源
```

- 编号是文字（`<em>`），会被朗读器读出、会被截图带走；
- 当前态 = **下划线 + 文字提亮**，不靠背景色块（深色底上几乎看不出）；
- 右上角只留：**时间基准徽章 · 算法身份 · 运行区域 · 投影模式 · 演示模式**；
  「信息密度」降级进「运行设置」（它改的是默认折叠状态，不是业务判断）。
- `SECTION_NAMES` 仍是**分节名唯一来源**；新增 `navCoverageGap()` 闸门：
  任何一个分节没挂进 `NAV_GROUPS` 就报红 —— 漏挂的样子是"那页永远打不开"，
  而构建、导航、既有判据三处都**不会**报错。

### 3.2 四个新页（手册 §10）

| 页 | 只回答 | 关键设计 |
|---|---|---|
| 走廊剖面 | 这条走廊几点能飞、凭什么 | 0–3 h / 3–6 h 两段分色不合并；判据清单带阈值与来源站号；无站区域不给"可飞" |
| 模型卡 | 模型准不准、比基线强多少 | 四条口径并排（工作点 / 0.5 / 三条基线），**输的那格也印**；混淆矩阵 / 可靠性 / 概率分布三张 SVG；失败样本 20 例（全部来自 test） |
| 反事实对照 | 用 AI 和不用差多少 | **重放**而非双跑（同 seed、同场景、同快照，只换裁决）；三档风险偏好；结论句由后端给 |
| 分歧台账 | AI 与规则不一致时人怎么判的 | 空台账如实说空；低置信（<0.65）记录单独标出 —— 那批复盘价值最高 |

四页的共同约束：**前端不重算任何概率**。判据里有一条专门盯着它（组件内不得出现自己的 0.8 / 0.5 阈值比较）。

### 3.3 命令面板（Ctrl+K）

可搜：页面名 / 走廊号 / 班次号 / 指标名（TS、FAR、POD、Brier）。↑↓ 选、回车执行、Esc 关。
走廊与班次清单**来自当前载荷**，没载入时如实说"尚未载入"，不塞示例。
`P` 切投影模式；投影模式记在 localStorage（刷新不该又变回看不清的那一版）。

### 3.4 穿帮清零（手册 §6.4）

手册给的是"浏览器控制台粘一段 JS"，只看得见当前这一页、跑完就没了。
本版做成闸门 `tools/maintenance/_scan_copy_leaks.py`：

- 扫源码（19 个 `.vue` + 8 个 `.js`），**剥注释**后只报会渲染到屏幕的字符串；
- 8 条禁用词各带一句"为什么致命"；`--self-test` 做负向验证（种一句必须抓到、注释里同一句必须不报）；
- 现状 **PASS 0 命中**；两条明确豁免（`不支持` 的能力边界、`mock` 变量名）写在脚本里留痕。

本轮清掉的三处：
