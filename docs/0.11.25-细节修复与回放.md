## 一、E-1：「资源或耗时不足」到底是什么

**它不是天气，是排不进去**，而且**一个名字对应五类拒绝**。后端
`service.py::_assign` 在五个地方把 `first_rejection` 设成它：

| 序 | 判据 | 一句话 |
|---|---|---|
| ① | 加完地面等待后总延误 > `max_extra` | 等太久，不如关 |
| ② | 单班飞行时长 > 该机型上限 | 这一趟本身超时 |
| ③ | 起降时隙排不进（`calendar.window_available(pad_entries)`） | 起降点被占满 |
| ④ | 交叉管制区时间窗排不进 | 穿不过去（容量） |
| ⑤ | 与已接受班次分离冲突（`conflict()`） | 撞了 |

**它晴天一样会发生**，所以口径上不计入"气象造成"。要判断具体是哪一类，看事件卡的
关联班次（`conflictWith`）与处置建议。

### 本轮改动

- 术语表（口径与来源页）新增「运行与处置 / 资源或耗时不足」：把这五条判据写进 `full`，
  这样"这是什么"在站内能查到，不用问人。
- 处置建议原本已有一句，保留：*"已声明高度层、起降与交叉资源或额外耗时均无法满足。
  先尝试改时隙或换备用高度层。"*

## 三、F-1/2/3：背景框没覆盖 = 内容跑出容器被静默裁

### 真相

三处症状，同一个病根：**内容比容器宽，被上层 `overflow-x:hidden` 裁掉**。
看起来像"背景没画满"，其实是右边那半截没了。

写了 `tools.probe_overflow`（把 12 页 × 1080 视口逐个元素量 `scrollWidth` 与 `right`）扫出来的：

| 位置 | 实测 | 原因 |
|---|---|---|
| 地图底部状态条 | `scrollWidth 1067` / 容器 `498` | `.text` 是 flex item，默认 `min-width:auto` ⇒ 写了 `ellipsis` 也不收缩 |
| 逐站观测表（图1 那个导出按钮被切一半） | 9 列把 `.briefing-block` 撑到比视口宽 | 表格没有自己的滚动层 |
| 推演右侧 aside（图2） | `640 + 210 + 14 > 内容宽`，多出的被裁 | `.ded-body` 不换行 + `aside` 写死 210px |

### 改法

1. `.city-map-info-status{min-width:0}` + `.text{min-width:0;flex:1 1 140px}` + 整条允许换行；
2. 逐站观测表包进 `.table-scroll{overflow-x:auto}`（**宽表必须有自己的一层滚动**，
   靠外层裁就是静默消失）；
3. `.ded-body{flex-wrap:wrap}`、`.ded-svg{flex:1 1 320px}`、`.ded-facts{flex:1 1 210px}`；
4. 推演 aside 补**统一底板**：原来只有里面的 `.ded-io` 有浅底，下面是裸的 ——
   屏幕上就是"背景框只盖了上半截"。现在整块 aside 一块底，`.ded-io` 退化成左边一道竖线。

### 复测

12 页 × 1080 视口：`doc 1050/1050` 全过；地图状态条从 `1067` 收敛到 `751`
（徽标换行，最长那行不再出屏）。

## 四、W-2：城市气象增强

| 你提的 | 改法 |
|---|---|
| 字大一点 | 行字号 **12 → 13px**，行高与内边距同步放大 |
| 下面不留空白 | `align-self:stretch` + 内部 `flex:1 1 auto`，面板吃满右栏第二行 |
| 加风向风速 | 后端 `current` 增 `wind_direction_10m`，按 8 方位转中文（"西北风"）；前端每行多一列 |

（一滚就跳回去）。现在自动播放只是"没人碰的时候帮它滚"。

实测：`72 行 · 首行「☀ 沈阳 晴 5.1℃ 西北风3.4m/s」· 字号 13px · 自动滚动 125→162 ·
滚轮后 scrollTop 402`。

## 五、B-2/3/4：复盘回放「真的能放」

### 三个问题叠在一起

1. **`v-if="journal.length"`**：一个刚建好场、谁都没点过的新工作区，回放面板**根本不出现**。
   于是只能得出"复盘没做完"。
2. **回放自己的时钟**：`replayMinute` 是组件内部的 0..日志最大分钟，与全站 `minute` 无关 ——
   拖动它，地图/气象/判据一动不动。
3. **`replayWeatherFrame` 的 ABSENT 分支缺键**：返回 `{state,label,note}` 没有 `tiers`，
   而模板写的是 `replayWeather.tiers.stratiform` ⇒ 一渲染就抛
   `Cannot read properties of undefined (reading 'stratiform')` ⇒ **整页渲染中断**，
   回放面板跟着消失。这一条是"面板不出现"的第二重原因。

### 改法

- 面板不再依赖日志：没有操作记录时给一句"时间轴照样能放，它驱动的是全站时钟"。
- 回放**直接驱动全站时间轴**：`emit('seek')` → 父级改 `minute`。上界用
  `maxMinute`（案例 360 / 实时 480），不再被"日志写到哪"限制。
- 加「▶ 开始回放 / Ⅱ 暂停回放」：每 180 ms 前进 2 分钟（480 分钟约 43 秒放完）；
  每步读 `props.minute`，用户中途拖时间轴会从新位置继续。
- `ABSENT` 分支补齐同一套键（**缺值可以，缺键不行**）+ 模板 `tiers?.` 双保险。

### 实测

```
回放面板: true
空态说明: 本计划还没有操作记录（没人点过处置）—— 但时间轴照样能放…
时间轴: max=480 value=60
点播放 → 60 → 70 → 82 → 92 → 104 → 116 → 126
页头时间基准: T+01:00 → T+02:06   （全站时钟真的跟着走）
按钮: Ⅱ 暂停回放      错误: 0
```
