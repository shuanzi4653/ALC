# V1.0.8 更新记录（2026-11-12）

## 1. 一句话

把地图上**看不见的城市点**补回来：319 个城市里 263 个是三级节点，原来半径 1px、填充 34% 透明、无描边，全国视图下等于隐形 —— 于是出现"只有城市名、没有点"和"航线悬空"的观感。

## 2. 问题

用户 18:52 在线上截图指出：乌兰察布、大同、廊坊、衡水、德州这些城市**只标了名字，没有点**；而天津、石家庄、太原、济南有灰蓝点。航线飞到没有点的城市，看起来像一条悬空的线。

查 `nation.payload()` 的节点分布：

| rank | 含义 | 数量 |
|---|---|---|
| 1 | 省会 / 直辖市 | 30 |
| 2 | 有机场城市 | 26 |
| 3 | 一般地级市 | **263** |

`NationMap.vue` 的节点圆点半径是 `rank===1 ? 3 : rank===2 ? 2 : 1`，三级还额外 `stroke: none`、填充 `--map-node-dim`（深色主题 `rgba(214,236,255,.34)`）。

也就是说：**63% 的城市点只有 1px、34% 透明度、没有描边**。1px 在 1366 宽的三倍屏上都只有 3 个物理像素，34% 透明度再把它压进底图 —— 视觉上就是"没有点"。

## 3. 改法

| 项 | 改前 | 改后 |
|---|---|---|
| 半径 | 3 / 2 / **1** | 3.2 / 2.6 / **2.0** |
| 三级描边 | `none` | `var(--map-node-stroke)`，宽 0.45 |
| 三级填充（深色） | `rgba(214,236,255,.34)` | `rgba(214,236,255,.62)` |
| 三级填充（浅色） | `rgba(34,74,108,.5)` | `rgba(34,74,108,.68)` |

描边比单纯放大填充更有效：它把点从底图上"抠"出来，不会因为点变大而糊成一片。省会与机场城市仍靠 3.2 / 2.6 的大小差与环形保留层级。

实测（本地，1366×768，deviceScaleFactor=2）：`nmap-nodes` 下圆点 **319 个**，半径直方图 `{3.2: 30, 2.6: 26, 2.0: 263}`；抽查乌兰察布 / 大同 / 衡水 / 德州均为 `r=2.0`、`fill: rgba(214,236,255,0.62)`，廊坊为 `r=2.6`（有机场）。深浅两主题 3 倍放大目视：每个城市名旁都有清晰圆点，名字有底衬未被压住。

## 4. 影响面

- 只改前端渲染（`NationMap.vue` 节点块 + 两个主题变量），后端与载荷零改动。
- 全国视图中点密度上升（319 个而不是视觉上 ~56 个），西南与华东局部略密，这是"所有城市都要有点"的必然代价。
- 城市名标签的显隐逻辑（避让重叠）未动，所以**有名字的城市一定有点，有点的城市不一定有名字**。
