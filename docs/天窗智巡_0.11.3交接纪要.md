## 3. 硬约束与踩过的坑（照抄，别重走）

1. **Python 改动不走 jar**：jar 只含 Java + 静态资源。改 `backend-python/**` 必须重打 `py-<ver>.tar.gz` → `scp` → `tar xzf -C /opt/apps/AIC-tianchuang` → `systemctl restart AIC-tianchuang-python`。**本轮踩过**：jar 部署后结论条仍是旧文案。
2. **打包顺序**：`mvnw clean` → 前端构建到 `backend-java/target/generated-resources/static` → 写 `build-info.json` → `mvnw package`（**不再 clean**）。顺序颠倒会把 static 一起删掉，jar 里没有 `index.html`，而部署脚本只看 health 照样报成功。

6. 工具链闸门：`backend-python\.venv\Scripts\python.exe tools/maintenance/_gate_toolchain.py`（含版本一致性、穿帮扫描、网关路由、文档链接）。
