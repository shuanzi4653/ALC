## 1. 事实基线（施工前必须承认的六件事）

1. **走廊是 269 条，不是 53 条。** `CAR` 53 + `DELIVERY` 216。所有"全网"口径必须写清是哪一种。
2. **`limit` 硬上限 40**（`main.py:422`），而 CAR 有 53 条 → 41–53 永远取不到。53 条**全部算过**，只是没返回。
3. **`ai` KPI 的 100 是常量**（`v2.py:701`）。
4. **`diverged` 漏计 `obs_ban` 分支**（`v2.py:900`）→ 反事实"改判 0"。
5. **`POST /traffic/session` 不认识 `case`**（`main.py:503`）→ 计划、页脚处置、台账状态全都是实时的。
6. **案例文件里没有雷达帧。** `data/traffic/cases/fog-20250105.json` 只有 `history`（7 h × 3 站 METAR）与 `frames`（visM/gustMs/dewSpread/cloudBaseM）。**没有 `cma_tiles` 瓦片、没有风险区几何、没有 Open-Meteo 延伸。**

> 第 6 条是全部方案里最重要的约束。执行方案 W-14 写"用案例时刻的气象重建一次调度"——`service.session()` 的调度链里有 `_radar_avoidance()`→`weather_control.radar_frame()`→`cma_tiles`。案例没有雷达，那条路要么**跳过雷达层**（于是案例的处置口径与实时不同源，等于用第二个假话补第一个假话），要么**造雷达帧**（造假）。
> **所以"让案例真的重跑调度"不是一个 6h 的活，是一个要么 12h+ 且口径分叉、要么越界造数据的活。** 我按"降级 + 明写边界"排（W-14），并把"真重跑"列为**有条件可选项**。

### W-17a · 修 `diverged` 计数（0.5h，P0）

**现在**（`v2.py:899-901`）：

```python
reviewed += 1
if fused != rule_level:
    diverged += 1
```

**问题**：`obs_ban` 分支（0.11.3 新增）不进 `if`，所以它改判了 3048 架，`diverged` 还是 0。

**改成**：

```python

changed = (fused != rule_level) or obs_ban          # ← 观测档改判也是改判
if changed:
    diverged += 1
```

同时把 `records` 里加 `'changed': changed`，让逐条明细能与合计对上。

**验收**

**界面断言**：反事实页副标"模型改判 **N** 架次"里的 N 必须 > 0，且 **约等于** B 组处置架次（3048）。两者差值只允许是"规则本来就判停、AI 又改了动作"的那几十架。

### W-13f · 前端 `case` 全量透传（2h，P0）

**现在**：只有 2 处拼 `caseQuery()`。后端 4 个接口全支持。

**改什么**：给这 4 处请求补 `${caseQuery()}`，且**不许再各拼各的**——统一走 `caseMode.js` 里已有的函数：

| 文件 | 请求 | 现在 | 改成 |
|---|---|---|---|
| `CorridorPanel.vue` | `/api/traffic/v2/corridor/{id}` | 无 case | 加 `${caseQuery()}` |
| `TrafficWorkbench.vue` | `/api/traffic/v2/corridors`（若存在） | 无 | 加 |
| `OperationsConsole.vue` | `/api/traffic/v2/corridors` | 无 | 加 |
| 首页 KPI 下钻 | 同上 | 无 | 加 |

**注意**：`corridor/{id}` 的 path 参数在前、query 在后，`?case=` 要用 `?` 起头而不是 `&`。`caseMode.js` 现在的 `caseQuery()` 返回 `&case=...`，对没有其它 query 的 path 会拼成 `.../CAR-x&case=y` —— **这是错的**。必须新增 `caseQueryFor(url)`：

```js
export function withCase(url) {
  const value = activeCase()
  if (!value) return url
  return url + (url.includes('?') ? '&' : '?') + `case=${encodeURIComponent(value)}`
}
```

**这条是真 bug 的前置**：如果只加 `&case=`，`/v2/corridor/CAR-1-01-1-05&case=fog` 会 404 或把 `case` 当 path 的一部分。

**验收**

  case "$p" in *\?*) sep='&';; *) sep='?';; esac
