## 2. 虚拟气象：这一版到底换了什么

这是本轮唯一改到数据侧的地方，写清楚边界：

```
虚拟 = 换一份能见度
        ├─ _fog() 由能见度派生 → 雾区自然跟着变（不是另画一层）
        ├─ nation_ops.flight_objects() → WEATHER_HOLD 与绕飞按同一套判据重算
        └─ 气温 / 风 / 湿度 / 气压 → 原样不动（逐值可对）
```

| 项 | 实测气象 | 虚拟气象 |
|---|---|---|
| 回波片数 | 214（49 / 69 / 96） | **84**（12 / 36 / 36） |
| 回波形态 | 真实拼图矢量化 | 6 个对流系统 × (2 层状罩 + 6 单体 + 6 强核) |
| 雾区 | 11 城 / 11 片 | **104 城 / 45 片** |
| 停飞（HOLD） | 4 架 | **24 架** |
| 绕飞 | 2 架 | 1 架 |
| 气温 / 风 | 实况 | **逐值相同**（测试钉住） |
| 能见度读数 | 实况 | 合成值，**带「虚拟」标记** |

界面上同时给出两点：页头一条说明条（"回波为合成对流系统、雾区按虚拟能见度派生；气温、风等要素仍为公开源实况"），情报表的能见度格加一枚「虚拟」小标。
