# AIC V1.0.2 发布说明

> 发布：2026-11-11　|　基线：V1.0.1（tag `v1.0.1`）
> 定位：**把"全国 → 大区 → 省 → 市"从一个页面，提升为贯穿全部入口的统一作用域**
> 本轮不推送远端（按用户要求本地发版）

---

## 0. 一句话

V1.0.1 的全国层只做成了一个 tab（`national`），系统本体仍是东北那套：
`home` / `overview` / `weather` / `alerts` / `assistant` / `profile` / `card` / `reference` / `history`
九个视图全部由 `OperationsConsole` 渲染，只吃东北的 `session`。

V1.0.2 把作用域提到全局（`frontend/src/traffic/scope.js`），九个视图全部作用域化；
在此之上补两块能力：**机场净空扩到 287 机场**（DERIVED）与**降级三态纪律**。

## 3. 新增能力

### 3.1 机场净空扩到 287 机场（v3 §3）

- 数据：OurAirports（airports.csv + runways.csv），`iso_country=CN` 且 type ∈ {large, medium, small}，
  排除直升机场与已关闭 → **287 站**，其中 **10 站有跑道方位**。
- 几何（全部 `DERIVED`）：限制区 R=8 km（运输）/ 5 km（支线）、巡视区 R=2 km、
  跑道净空梯形（两端延长 10 km、半宽 1.5→3 km，**仅 10 站有跑道方位才生成**）。
- 穿越：492 条航线 × 287 个限制区，STRtree 一次查完，**113 条穿行（23%）**，0.48 s。
- **纪律**：`DERIVED` 与东北 69 站点的 `OFFICIAL` 分开计数、分开上色，界面上写明"非官方公布"。
- 载荷：主载荷只放计数摘要（几百字节），几何与穿越明细走 `/traffic/v2/nation/zones` 按需取。
  直接把 287 个环塞进主载荷会多出 250 KB（实测 733 KB），已回退为 479 KB。

### 3.2 全局作用域

- `frontend/src/traffic/scope.js`：`scopeKey` / `parseScope` / `readScopeFromUrl` / `writeScopeToUrl`。
- URL 形态：`?scope=province:河北省#/situation/home`（放在 hash 之前，不动项目的 hash 路由）。
- 切层清空班次/走廊/跟随；下钻只走一个入口（地图、右栏、命令面板都调 `go()`）。

## 4. 收尾补齐（2026-11-11 07:xx，本轮新增）

发布说明第一版把下面三项列为"未做"，本轮已补齐；`docs/V1.0.2-更新方案.md` §5.4 的四条护栏全部落地。

### 4.1 三维全层级（T19/T20）

| 护栏 | 落地方式 |
|---|---|
| ① 能力探测 | 新增 `frontend/src/traffic/gpu.js`：`getContext('webgl',{failIfMajorPerformanceCaveat:true})` 拿不到上下文即判软件渲染（比字符串匹配权威），再用 `SwiftShader/llvmpipe/Mesa OffScreen` 兜一层。软件渲染**不建图**，直接退回倾斜视图并写明原因。 |
| ② 要素按层级裁剪 | 全国只给 **31 个省会**起柱（319 城铺满会变棋盘）；大区 rank≤2、省/市全量。柱高按缩放归一（`interpolate zoom`），否则 0.5° 宽的柱子在省层会变成一堵墙。 |
| ③ 帧率看门狗 | `startFpsWatch`：宽限 2.5 s，连续 3 秒 <20 fps 回调 → 退出三维、落到倾斜视图、提示"多半是显卡没走硬件加速"。低帧时先自动摘掉 DEM 再试一次。 |
| ④ DEM 只在近层 | 省/市层挂 `raster-dem`（terrarium，`maxzoom:6`，实测 200 / 88 KB 可达）；全国层不挂。 |

**四级通用**：全国（固定相机 + 底部 92 px 内边距避开浮层）、大区/省/市（`cameraForBounds` 而不是 `fitBounds` —— 后者完全不管俯仰，带 pitch 取景会把整幅图缩成一小块）。浏览器实测 241 fps，全国→大区→省一路下钻不降级。

**踩到的两个坑**（都已写进代码注释）：
1. maplibre 的 `zoom` 只能出现在**顶层** interpolate/step 里。写成 `['*',['get','h'],['interpolate',...,['zoom'],...]]` 会让整份样式编译失败，而失败的表现不是报错 —— 是 `load` 永不触发、界面一直停在"初始化"。已加 6 秒样式校验兜底。
2. 样式里引用运行时 `addImage` 的图标（飞机）会先刷一条 "Image could not be loaded"。把 `flight-icon` 层从 style 里挪出来、`load` 后再 `addLayer`，顺序问题彻底消失。

### 4.2 双受众视角（T15 后半）

同一套几何两种读法，不做第二套数据：

| | 运行视角（默认） | 空域视角 |
|---|---|---|
| 地图 | 航线为主，净空圈只在省/市层做底图 | 净空圈为主（平面 + 三维柱），航线降到 38% 不透明度、航班图标降到 30% |
| 侧栏 | 大区/省/市逐级 + 气象 | 顶部插一块「空域净空」：受限额 287 机场 / 限制区 287 个 · 35 283 km² / 覆盖率 0.37% / **待审穿越 113 / 492（23%）** + 穿越 Top6 |
| 等级 | — | `可申请穿越` ⇄ `一律禁飞` 一键整体切换（演示用，界面写明"真实世界里这是审批结果不是开关"） |

**顺带修掉一条真 404**：`/api/traffic/v2/nation/zones` 在 Python 侧一直是 200 / 237 KB，
但 Java 网关只透传显式声明过的路径，`{resource}` 单段白名单接不住 `nation/zones` →
前端一打开空域视角就报"净空几何不可用"。已在 `DecisionController` 补该路由。
**这类"后端有、网关没有"的路径不会在单测里暴露**，因为前端接的是网关。

### 4.3 推演个性化

推演页顶部加"立题行"：**选城市**（121 个，省会/机场城市排前）+ **选班次**（按呼号排序），
选城市即把作用域切到该市（面包屑跟着走），选班次即驱动右侧从实况 → 判据 → 裁决的完整链路。
之前这一页只能在地图上盲点，点不中就什么都没发生。

### 4.4 顺手修掉的两处噪声

- `/favicon.ico` 404（浏览器无条件请求）：改为内联 SVG 图标，控制台彻底干净。
- 雷达中继：瓦片源没开 CORS 时，一次取图会连打 6 个时次 × grid 张图、每张留一条 CORS 红字。
  改为**一次失败即标记 `relay.corsBlocked`**，本轮不再往后试（后端直取不受影响）。

### 4.5 全站文案与界面清理（2026-11-11 08:xx）

原则只有一条：**界面上出现的每个数字和每句判断，都要能被同一屏的数据或可复算的规则解释**。
不能解释的，要么删掉，要么改成"规则说明"而不是"实时播报"。

**① 首页右下角不再挂「边境城市」名单**
原来那里是一张折叠卡：「边境 50 km 内 11 城已退出通航」+ 逐城距离。数字与名单都随数据变，
摆在首页右下角会被读成"有一条正在发生的告警"—— 它其实是**建网规则**。
现在：首页只留一句规则（图例内：边境 50 km 内侧城市整体退出通航，保守取值），
名单与逐城距离移到「运行情报 · 空域情报」的「纳入范围」脚注里，和机场表放在一起。

**② 修掉一句自相矛盾的判据**
处置页原来每张卡的详情都是「风险概率 0.05，高于 0.75 暂不放行」——
0.05 当然不高于 0.75。真实原因是 **HOLD 有两条判据**：规则风险 ≥0.75，或模型低能见概率 ≥60%，
当时触发的是后者。现在按实际触发的那条写：
「模型低能见概率 74% ≥ 60%，暂不放行」/「规则风险 0.82 ≥ 0.75，暂不放行」。

**③ 表头与内容对齐**
- 台账表头「班次 / 机型」→「班次 / 类型」（那一列写的是省内/机场接驳/跨省，不是机型）。
- 口径总账末列「负责人」→「计算方」（值是后端/规则引擎/模型，不是人）。
- 气象表补表头「城市 / 概率 / 温度 / 风速 / 能见度」—— 那一列 99% 是 ml-v3 的低能见概率，
  没有表头会被读成降水概率。

**④ 三个入口不再长得一模一样**
「调度台账」「班次情报」「大模型取证」共用一张表，但表头与排序按用途分开：
台账按起飞时刻、给申请/计划/实际；情报按风险从高到低、给判据与裁决；
取证页叫「选取证对象」。之前三页标题都是「全国班次台账」，只是导航名字不同。

**⑤ 一个页面只讲一次口径**
运行情报页顶栏与组件内条各有一句"交通为模拟、气象为公开源"，同一屏说两遍；
组件里那句删掉，作用域与口径统一由顶栏说。

**⑥ 建场进度条只出现在会用到计划的页面**
日志页、口径页顶上原本压着一条 86% 的蓝色进度条，既盖正文又与页面无关。

**⑦ 左栏提示按现在的页面重写**
「一屏结论：现在哪片天不能飞」这类提示还停留在东北单页时代，现已按全国四级改写；
「走廊剖面」原写"右侧给出剖面"，实际在**下方**。

**⑧ 其它**
- `border.note`、`discipline`、`cma_tiles.note` 三处数据层文案里的 Markdown `**` 会原样漏到界面，改为「」。
- 首页头部由"一句话几十字"改为三行：面包屑（我在哪）/ 态势一句话（这一刻）/ 规模与口径（这个视图覆盖什么）。
- 右栏区块卡片由两行改一行、气象表吃满剩余高度：6 个大区从"只看得到 2 个"恢复到全部可见。
- 空域情报的「逐市实况」收成折叠块，56 行的机场表不再被挤到只剩 4 行。
- `favicon` 内联，消掉控制台唯一一条 404。

### 4.6 删除城市体块柱 + 深浅色 + 界面美化（2026-11-11 08:xx）

**① 那些"透明方块"是体块柱，已全部删除**
三维视图里每个省会头上一块半透明方块，是 `fill-extrusion` 起出来的"示意柱"
（当时想用高度编码"风险堆积"）。但全国缩放下
z3.5 时 1 px ≈ 16 km，柱子只有 2–4 px 宽、3–6 px 高 —— 读者看到的是**飘在点上的玻璃方块**，
不是数据。与其加注"这是示意"（已经在两处注过了），不如删掉：
城市改用点 + 环（省会浅环、低能见红环），三维里保留的体块只剩**机场净空柱**
（省/市层，垂直放大 10×，界面上写明）。
顺带把 `NationGlobe` 里的体块配置、数据源、图层、按层裁剪逻辑一起清掉。

**② 深浅色（顶栏「浅色 / 深色」）**
- `src/theme.js`：`data-theme` 开关 + localStorage 记忆 + `MAP_PALETTE` 两套地图色。
  `main.js` 在挂载**之前**落主题，避免先闪一帧深色。
- `src/theme-light.css`：覆盖层。不重写组件（236 KB scoped 样式，颜色是散落字面量，
  重写等于把 V1.0.0 以来的排版判断全部重做），而是按「面 / 线 / 字」三类覆盖。
  **Vue scoped 样式会追加 `[data-v-x]`，特异性天然高一级**，所以覆盖层必须带 `!important`，
  左侧竖排导航那几条还要再加一级 `body` 才压得住 —— 这是这轮最容易踩的坑。
- 地图：`NationMap` 的结构色改成 CSS 变量（`--map-*`，深浅两套），`NationGlobe`
  在主题切换时走 `setPaintProperty` 改 10 个图层的颜色，**不 `setStyle`**
  （重建会丢相机与图层顺序，还会闪一帧白）。
- 三维城市名 `text-shadow` 在浅色下必须反过来（白底黑字带白描边），否则一片白雾。

**③ 界面美化（只做不改布局的三件事）**
- 统一过渡曲线：按钮/下拉的 background / border / color / box-shadow 都走 `--alc-ease`；
- 键盘焦点可见：`:focus-visible` 用 `--alc-info` 画 2 px 环（原来键盘操作完全看不到焦点）；
- 地图画布一层极轻投影（深色下近黑、浅色下近蓝灰），把"图"和"栏"分开。

**验收**：前端 **501** 通过（新增 7 条主题用例）；浏览器 **27/27**（含"切浅色 → 底色变 →
地图换肤 → 写入 localStorage → 能切回"五步）；深/浅两套各截首页与三维，控制台 0 报错。

## 8. 已知限制（与 V1.0.1 相同，未变）

1. 交通是 `SIM`，不参与运行计划与裁决；红线只由东北 53 条走廊产生。
2. 全国风险概率是 `MODEL`（ml-v3，logistic 28 维）与 `RULE` 两套判据并存，任一触发即降级。
3. ml-v3 输入与标签同源（open-meteo 模式能见度），指标衡量的是"模式能见度的演变可预测性"；
   `precision 0.2588`——4 次报警有 3 次是假的，低 TS 主要来自误报多不是漏报多。
4. 气象备源（wttr.in）只补 80 城；主源限流时一般城市没有实况是预期行为。
5. 台湾、西藏、香港、澳门不纳入通航；地图本身按国标实线完整绘制。
6. 边境 50 km 退出是本系统保守取值，条例只写"一定范围"。
