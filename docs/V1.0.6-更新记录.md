## 2. 修掉的 8 个缺陷

| # | 症状 | 根因 | 修法 |
|---|---|---|---|
| 1 | 打开旧地址 `#/corridor/briefing` 落在**运行首页** | `applyHash` 里 `known` 只查 `SECTION_HASHES`，旧地址不在表内 → 直接改写 home，把刚解析出的 weather 覆盖掉 | 统一按"解析后的分节"回写地址栏：地址永远等于页面，旧地址顺手升级 |
| 2 | `#/situation/national` 地址写着 national、页面是 home，刷新又跳一次 | 同上，national 在表里所以不改写，但页面被归一到 home | 同上 |
| 3 | 算法机理 / 反事实 / 分歧台账三个隐藏页左侧**一个都不亮** | 入口高亮用 `activeSection===sub.key`，而这三页是别人 members 里的成员 | 改为 `sub.members.includes(activeSection)`，落在入口的"上下文"态（弱高亮） |
| 4 | 点日志行落到**走廊剖面**，六段链路看不到 | `openJournalRow` 与处置共用一个 emit，工作台固定跳 profile | 载荷加 `target:'card'`：处置→剖面（人工裁决），日志→推演（六段） |
| 5 | 调度台账**没有搜索、没有导出** | V1.0.5 把东北台账表换成 `NationBriefing` 时丢了这两个能力（功能回退） | 组件内补搜索（班次/城市/航线）与 CSV 导出（前端生成，不占接口） |
| 6 | 走廊页航线只有 **4–34 px**，看不出从哪到哪 | 地图容器只有 240 高，SVG 按高度等比缩放（1000×640 塞进 940×240），横向大量留白 | 容器抬到 380（推演 360）+ 定位缩放上限 4.2 → 6；实测 4→10、18→40、27→61、34→76 px |
| 7 | 点选一架飞机后航线跑出视野下方 | `pan` 是屏幕像素，而 `cx/cy` 是 viewBox 坐标，三处（focusPts/fitBounds/centerOn）混用量纲；zoom 小的时候误差被余量吃掉，放大到 6 倍就偏出去 | 抽出 `viewScale()` / `centerWorld()` 两个函数，量纲只在一处定义；滚轮与拖拽同步改成屏幕量纲 |
| 8 | 空格键不响应；播放按钮写着"▶ 推演"，与右侧同名入口混淆 | 无快捷键绑定；文案沿用了内部叫法 | 加空格播放/暂停、左右键 ±1 分钟（输入框内自动跳过）；文案改"▶ 播放" |

## 4. 未做 / 需要你定的

1. **反事实页与算法机理页顶部仍有「东北三省 · 全域」的城市下拉**。这两页确实基于东北会话（反事实要同一份计划、机理页讲的是那 1332 班），所以下拉在语义上不算错；但它与全国 319 市的叙事并列时容易被误读。建议下次在这两页标题下加一句"本页基于东北运行网（裁决层）"。本轮没动，因为要改的是两句文案的定位，值得你确认口径后再改。
2. **`HomeStage.vue`（619 行）与 `ModelCardPanel.vue`（434 行）仍未删除**：无 import，但 7 个测试文件读其源码。删组件要连用例一起删，用例数会从 507 掉下来。
