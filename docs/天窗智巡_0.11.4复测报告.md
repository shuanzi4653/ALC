### 2.1 P0-A：首页说"21 条禁飞"，处置台说"气象成因 0"

**复现路径**：`https://tianchuang.shuanzi.site/?case=fog-20250105` → 看首页横幅与 KPI → 点「处置这 53 条 →」→ 处置台。

**首页（同一屏）**：

```
历史回放 · 非实时  2025-01-05 沈阳大雾
ZYTX 实测能见度 997.8 m、云底 152 m；同一小时哈尔滨 1593 m、长春 2993 m。
本案例回放观测与判据，不重跑航班调度；航班状态仍为实时推演，勿与本页处置数字对照。

沈阳 ↔ 本溪 等 21 条走廊当前观测已达禁飞级（三站最低能见度 998 m）…

   53条  待处置走廊        21条  禁飞级走廊        60分钟 平均提前量      100% 模型覆盖
                           CAR-1-01-1-05、CAR-1-01-1-04、CAR-1-01-1-12

运行事件 361 个 · 停止放行 123 班
```

**处置台（点进去第一屏）**：

```
事件处置台 全域 · 361 个合并事件
361 个事件 / 涉及 3623 班 · 停止放行 123 班
停止放行 123 班，其中气象成因 0 班 —— 不要把这一屏读成天气造成的
气象成因 0        非气象成因 361
停止放行中气象成因 0 班 · 非气象成因 123 班

当前窗口内的 361 个事件里没有气象成因的：停止放行 123 班全部来自排程越界（超出推演时段），
与天气无关。切到「排程冲突」可查看这些事件。
```

**为什么这是 P0 而不是 P1**：

1. 首页那 21 条走廊是**用观测档判出来的**（`verdictSource: OBSERVATION`），它确实进了"判据"这一层；
2. 但"判据"没有进"调度"这一层——**123 个停止放行全部来自 `BEYOND_PLANNING_HORIZON`（超出规划视界），一条都不是因为能见度 998 m**；
3. 结果就是：**模型判了 21 条禁飞，系统一架都没因此停飞**。这一句话，评委只要点两下就能自己得出。

**另外两个连带缺陷**（同一屏可见）：

- **文案指向一个不存在的 tab**：`切到「排程冲突」可查看这些事件` —— 全站按钮实测无"排程冲突"（只有 `气象成因 / 非气象成因` 两个 chip，且这两个 chip **默认同时是 `on` 状态**，见截图 03）。
- **非气象筛选的卡片标签写错**：点"非气象成因"后，每张事件卡的标签是 `排程冲突 / 待确认 / 超出推演时段 / BEYOND_PLANNING_HORIZON`，而卡片本身是"影响 10 班 · 停止放行 10"。**"排程冲突"在这里是二分类标签，不是 tab**——文案把标签当成了入口。

**最低成本的修法（1 小时，不改后端）**：

> 把处置台导语从"与天气无关"改成"**本案例只回放观测，不重跑调度；这 123 班是实时推演里超出规划视界的班次，与天气无关。要让天气进入调度，见「复盘 · 反事实对照」**"，并在同一行加一个跳到反事实的链接。
>
> 这一句把"打脸"变成"我明确知道边界在哪"，且把评委的下一步引到你们唯一做了真对照的那一页。

**正确的修法（6 小时，W-25）**：雾天案例建场时带 `case`，让 `weather_flights > 0`，首页"运行事件"里的深橙事件 = 气象成因。

### 2.5 P0-E：消融表数字真跑了，但结论分不清

四组实测（`?ablate=`）：

| 消融 | 风险暴露 A→B | 改判 | 延误 | 读数 |
|---|---|---|---|---|
| `none`（完整） | 3016 → 0 | 3048 | 32 班 / 1280 min | 基准 |
| `obs`（去掉观测档） | **0 → 0** | — | — | **全灭**：连 A 组都没有暴露 |
| `prob`（去掉概率档） | 3016 → 0 | 3048 | 1280 min | **与完整系统完全相同** |
| `loss`（去掉期望损失） | 0 → 0 | — | **3048 班 / 121920 min** | 全停，代价爆表 |

**问题**：`obs` 和 `loss` 两组的 A 组暴露都是 0，`prob` 一组与完整组一模一样。也就是说，**四组里只有"完整"和"prob"这一对是可比且有意义的，其余两组因为 A 组被清零而失去了对照意义**。

答辩时如果评委问"去掉观测档会怎样"，你的表会显示"暴露 0 → 0"——**这看起来像"观测档没用"**，而事实是"去掉观测档后 A 组已经没有任何暴露，对照失效"。修法：A 组必须在同一裁决规则下重算，或者表格里明确标出"该组 A 组已无暴露，差值不可比"。（执行方案 W-30）
