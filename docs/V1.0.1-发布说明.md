## 二、这一版新增了什么

### 1. 全国四级航线网（全国 → 大区 → 省 → 市）

| 项 | 数值 |
| --- | --- |
| 纳入城市 | 319（民政部区划 + Wikidata P625 坐标） |
| 省级单元 | 30（台、藏、港、澳不纳入通航，地图仍完整绘制） |
| 机场城市 | 56（aviationweather stationinfo） |
| 航线 | 492（省内 212 / 接驳 272 / 跨省 30） |
| 大区 | 6（华北、东北、华东、中南、西南、西北） |

建网规则：省内最小生成树 + 无机场城市专用接驳 + 省级最小生成树通道；
大连—烟台单独走跨海通道（标记 `geometry: SEA`）。
网络文件 `data/traffic/nation-network.json`，由 `tools/traffic/build_nation_network.py` 可复算。

### 2. 边境处置：让「飞出国境」不可能发生

**判据**：城市中心到**邻国多边形**的距离（Natural Earth 1:50m，固化为
`data/traffic/neighbors-50m.json`），不是到省界的距离。

- 距境外 < 50 km 的城市**整体退出通航**，节点与关联航线一并删除：11 城
  （黑河 0.9 / 丹东 1.2 / 塔城 8.3 / 怒江 19.9 / 延边 25.6 / 博尔塔拉 30.9 /
  白山 35.6 / 防城港 35.6 / 西双版纳 36.5 / 德宏 36.5 / 鸡西 44.8 km）。
- 越界监视改为**逐航路几何测量**：492 条按约 8 km 加密，逐点与邻国边界求距，
  10 km 为硬限、30 km 为预警带。实测最近 **18.2 km**，0 条进 10 km 带。

**表述纪律（答辩必守）**：《无人驾驶航空器飞行管理暂行条例》第十九条第二项
只写「一定范围」，**没有写公里数**。50 km 退出与 10 km 管制带都是本项目的
保守执行口径，**不能说成「法律规定的 10 km」**。

### 3. 班次对象化与运行处置

每架在飞都是独立对象：稳定编号（crc32，重启不换号）、申请 / 计划 / 实际三个时刻、
放行许可（航路、600–1100 m 高度带、时窗、条件）、9 点高度剖面、风险概率与裁决、
裁决依据、反事实暴露分钟。全国台账 106 架在飞 + 90 班待起飞，申请-计划-实际分列。

### 4. 概率换成真模型（ml-v3）

| 项 | 数值 |
| --- | --- |
| 训练数据 | 319 城 · open-meteo 逐小时 · 过去 30 天 · 227 447 条样本 |
| 切分 | 按时间 8:2，不打乱 |
| 测试集 AUC / Brier / TS | **0.9488 / 0.120 / 0.256** |
| 事件基线 | 6.6% |

**口径**：输入与标签同源（都用 open-meteo 模式能见度），所以指标衡量的是
「模式能见度的演变可预测性」，**不等于实测低能见度命中率**；这条写在情报页模型卡上。
规则分与模型概率**各自把关**，任一触发即降级，每架标 `MODEL` / `RULE`。

### 5. 气象：多源 + 后台刷新

- 主源 open-meteo 批量；被限流（429）或缺城过半时，用 wttr.in 逐城补
  （中文城市名可用、带能见度、限速 1.15 s/次，只补省会与机场城市共 80 个）。
- stale-while-revalidate：请求只读缓存，过期也先交旧数据并在后台线程刷新；
  首次无数据立即返回「补数中」占位，**不让首屏等一分多钟**。
- 落盘 `data/cache/city-weather.json`；每城带 `source`，界面能回答「这个温度是谁给的」。

### 6. 其他

- 雷达回波：RainViewer 公开瓦片，前后端双端裁到国界内，境外回波不显示。
- 绕飞：走廊穿回波沿法线侧移，琥珀色航迹；反事实给出「不绕飞将暴露 N 分钟」。
- WS 推送：网关每 5 秒拉一次心跳（雷达帧 / 实况时刻 / 模型版本），有变化才广播，
  页面空闲不再整包轮询。

## 三、修掉的缺陷（含根因，可复现）

| 症状 | 根因 | 修法 |
| --- | --- | --- |
| 地图上出现「红色小方框」伪影 | 强回波按 0.14° 聚网格，最小环 0.17°×0.39°，国家级缩放下不足 2×4 px，再按 0.9 px 描边就成了空心小方框 | 按**屏幕尺寸**分流：≥15 px 画双层等值线，小于则直接填实 |
| 后端进程随机崩溃（exit 139） | 心跳 `pulse` 每 5 秒也算雷达环数（shapely），但没走全国层串行锁，与主请求并发进 `make_valid` | 四个入口（payload / flights / pulse / evidence）统一 `_NATION_LOCK` |
| 逐市气象成片变空、接口被拖到 10 s+ | open-meteo 免费额度按小时计，一小时打满后连续 429，且原实现每批重试 3 次 | 429 立即放弃该批；多源补数；缓存 30 min；限流时空结果也缓存 5 min |
| 同屏两个时间基准（顶部 09:00、班次 22:24） | 后端 `_clock` 按 UTC、界面按本地 | 后端统一 UTC+8，与界面一致 |
| 调度台账横向溢出、一条占三行 | 列宽自适应 + 三个时刻竖排 | `table-layout:fixed` 定列宽，三个时刻并一行 |
| 全国页顶部挂一条 0% 进度条 | 东北建场进度条未按视图区分，全国网是 SIM 不参与建场 | 全国范围三个视图不显示 |
| 地图两侧各留两百像素黑边 | 中国版图宽高比约 1.28，屏幕约 2.0；且监视条与图例占掉 70 多 px 高度 | 监视条/图例改地图内浮层，把高度还给地图；右栏分档收窄 |
| 全国视图一次拉 140+ 张雷达瓦片 | 瓦片级别被写死 z6 | 按单瓦片 420 px 目标自动选级，上限 64 张 |
| 三维视图把浏览器主线程拖死 | 用 maplibre 起真三维（fill-extrusion + 高程）在测试机上两次导致 Edge 完全无响应 | **回退**为 SVG 透视倾斜；三维组件与瓦片代理保留未启用，恢复条件写在源码注释里 |

## 四、口径变化（对外表述要跟着改）

1. **航线数不可分省相加**。跨省航线在两端省份各计一次，六个大区之和是 524，
   全国总数是 492。块上已加 `title` 说明。
2. **「绕飞 N 架」与「穿回波走廊 M 条」不是一回事**：前者是在飞班次的延误计数，
   后者是当帧需要改航的走廊数。两者都随雷达帧变化 —— 实测同一分钟内
   绕飞航班 3 → 0、穿回波走廊 5 条，属于正常波动，不是数据错误。引用时须写明取数时刻。
3. **全国层的建筑体块是示意**（无全国建筑足迹数据），高度按风险派生，不是楼高。
4. **地形高程源在当前网络不可达**，立体视图不叠加地形起伏，源码与界面都如实标注。

## 五、未完成（诚实清单）

1. 立体是透视倾斜 + 体块 + 晕渲的示意三维，不是 maplibre 真建筑 / 真高程。
2. 训练模型、TS/Brier 三基线、反事实三基线、分歧台账仍只覆盖东北 36 城；
   全国层是 ml-v3 单模型 + 规则分双判据。
3. 越界监视是逐航路几何（已做），但停飞航路不排班，没有「虚拟待批航班」参与比对。
4. 大模型取证链在本地未配 api-key 时只走规则链，界面如实标 `NOT_CONFIGURED`。
