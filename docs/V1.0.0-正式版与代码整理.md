## 一、版本号：两条编号线合并成一条

此前仓库里并存两个号：登记材料里的 `V1.0`（受理号 `2026R11.3476201`）与代码里的
`0.11.x-beta`，`docs/NAMING.md` §7.1 专门写过"不得互写"。本轮按要求合并：

| 场合 | 写法 |
| --- | --- |
| 程序落点（`VERSION` / `pom.xml` / `package.json` / `package-lock.json`） | `1.0.0` |
| 散文（README 标题、文档、表格） | `V1.0.0` |

`0.9.0 … 0.11.27` 这条 Beta 线**收口于 `0.11.27`**，之后不再出现 `0.11.28`。

改的不只是六个数：

1. `tools/maintenance/_check_version_consistency.py` 的 `SEMVER` 从 `x.y.z-beta` 放宽到
   `x.y.z(-beta)?`，`_doc_form()` 对正式版产出 `V1.0.0`；
2. `--self-test` 新增**两条**：`V1.0.0` 正例、以及"正式版却写回 `0.11.27（Beta）`"负例——
   没有负例，`_doc_form` 改坏了要等真升级那天才发现；
3. `docs/NAMING.md` §7 重写：正式版的递增规则（主/次/修订）、合并说明与三条登记纪律；
   原 §7.2 的代位规则标注为「历史」，保留给旧版本查证。

`frontend/tests/f1f3f5.test.mjs` 里钉着 `^0\.11\.\d+-beta$` 的那条判据同步放宽——
否则版本一升，它报的是"VERSION 格式不对"而不是"版本不一致"，会把人引向错误的方向。

## 三、代码注释：搬进 `docs/代码注释归档-V1.0.0.md`

判据是机械的，写在 `tools/maintenance/_strip_comments.py` 里：**默认删**，只留功能性标记
（`# noqa` / `# type:` / `# pragma` / shebang / coding）与 ≤40 字的单行 docstring。

| 范围 | 文件 | 行数变化 |
| --- | --- | --- |
| `backend-python/`（不含 tests / experiments） | 44 | 18 323 → 11 720（−6 603） |
| `backend-java/src/main/java` | 70 | 6 325 → 5 152（−1 173） |
| `frontend/src`（Vue / JS） | 28 | 16 378 → 12 129（−4 249） |
| `application.yml`（jar 内资源） | 1 | 22 → 12 行 |

归档 1.5 MB 在 `docs/代码注释归档-V1.0.0.md`，**只在本地**：`docs/` 不上服务器、也不进 jar。

**三类刻意不动**，各有硬理由：

1. `db/migration/*.sql` —— Flyway 对迁移文件算摘要，改一个字符线上库就 `checksum mismatch`，
   应用直接起不来。注释再长也不能碰。
2. `tests/` 与 `backend-java/src/test` —— 不随产物发布，且注释里写着判据的由来。
3. `static/assets/*` —— 构建产物，打包时注释已被去掉。

### 三个坑（都在动手时踩到了）

1. **docstring 是块里唯一语句时不能删** —— `class X:` 后面空了就是 `IndentationError`。
   实测 2 个文件（`traffic/service.py`、`traffic/operations.py`）当场编译失败 ⇒ 退化成 `pass`。
2. **删整行注释要把缩进一起删** —— 第一版只删 `//` 之后的文本，留下行首空格，
   下一行的缩进叠在上面，Vue 里出现 `    planScenario:` 这种 4 空格错位。修法：
   若注释前只有空白，起点回退到行首。
3. **`<template>` 配对不起** —— `</template>` 常先出现在嵌套 `<template v-if>` 里，
   取第一个闭合标签只处理了文件开头一小段（实测残留 137 条模板注释）⇒ 改用 `rfind`
   并加一道全局兜底。

### 顺带抓出一条"空判据"

`tests/mapLayerContracts.test.mjs` 原先断言源码里有 `仅层状降水（可飞越，已标出范围）` ——
那串字**只存在于注释里**，而 0.11.5B 已把徽标改成「15–35 dBZ，可飞越」。注释一删，判据立刻红：
它守的其实是"注释里有这行字"。已改为钉真文案（必须出现 `仅层状降水`，且不得承诺`已标出范围`）。
