## 0. 怎么用这本手册

**一句话**：这是**动手册**，不是原理册。原理、口径、红线在硬件分册里，这里只回答"这根线插哪、这个焊点多亮算合格、屏不亮先摸哪里"。

**执行顺序不能换**：

```
§3 开箱核对  →  §5 免焊装配（D1–D4 全绿）  →  §6 焊接（可砍）  →  §7 装盒（可砍）  →  §9 签收
   10 min            60–90 min                  60–120 min           30 min
```

**为什么焊接放在最后**：面包板上改一根线只要 3 秒，焊死之后改一根要拆焊 10 分钟。**D1–D4 没全绿之前，烙铁不要插电。**

**符号约定**

| 符号 | 含义 |
|---|---|
| ⚠️ | 会烧板 / 会伤人，做之前先读 |
| ✋ | 停手检查点，不通过不许往下走 |
| ✅ | 判据，必须用数字或现象证明，不许"应该没问题" |
| ✂ | 可砍项，时间不够直接跳过 |
| 📷 | 需要拍照留证 |

**三条贯穿全册的铁律**

1. **断电插拔**。任何接线动作前，先拔 USB / 先关电池开关。
2. **上电前测短路**。万用表蜂鸣档测 `3V3↔GND`，响就停手。
3. **所有 5 V 与 3.3 V 不许互串**。屏、BME280、按键一律走 **3V3**，不许接 5V 脚。

## 1. 安全须知（做之前读一遍，两分钟）

### 1.1 六条硬规矩

| # | 规矩 | 为什么 |
|---|---|---|
| 1 | ⚠️ **不许直接给 18650 电芯焊线** | 电芯封不住会局部过热，有起火风险。只用免焊套件/电池盒 |
| 2 | ⚠️ **两节电芯并联前先测压差** | 压差 >0.1 V 并联会瞬间大电流互充，保护板发热。**压差 >0.3 V 就换一节** |
| 3 | ⚠️ **电芯不许反装、不许短路** | 反装可能击穿保护板；表笔/镊子横放在电芯上就是短路 |
| 4 | ⚠️ **烙铁 330–350 ℃，用完立刻归位并断电** | 烙铁头 350 ℃ 碰到杜邦线绝缘层 1 秒就穿，冒烟有毒 |
| 5 | ⚠️ **焊接必须在通风处，头不要正对焊点** | 松香烟雾刺激呼吸道，焊完洗手（含铅锡） |
| 6 | ✋ **每次改接线前拔 USB** | 带电插拔 3V3 与 GND 顺序不定，容易瞬间反灌 |

### 1.2 五条禁止清单

- ❌ 不许把 **2S 电池盒（7.4–8.4 V）**接到 S3 的任何脚。它只能接 Maker 板的 6–16 V 口。
- ❌ 不许给屏或 BME280 接 5V 脚（3.3 V 器件，5 V 会烧）。
- ❌ 不许用**只充电的数据线**烧录（现象：插上完全没反应，白折腾一小时）。
- ❌ 不许在**通电状态下**用万用表电阻档/通断档（读数全是错的，还可能烧表）。
- ❌ 不许"先凑合装"——§3 缺件或规格不符就停，等件。

### 1.3 桌面布置（5 分钟，省很多事）

1. 桌面铺一块**绝缘垫**或一张打印废纸（防止螺丝/锡珠滚进板底短路）。
2. 烙铁架放**右手边靠后**，烙铁线从桌后走，不要横穿工作区。
3. 电芯**单独放一边**，不要和散落的排针、螺丝混在一起。
4. 手机放远一点——它会在你焊屏排针时响。

### 2.2 万用表三个档位怎么用（本手册只用这三个）

| 档位 | 表盘标识 | 用法 | 读数判据 |
|---|---|---|---|
| **通断档** | 🔊 或 `)))` | 测线是否通、焊点是否连上 | **<50 Ω 蜂鸣**；不响且显示 `1` = 断路 |
| **直流电压 20 V 档** | `V⎓` 20 | 测电芯、测 5V、测 3V3 | 见 §9 记录表的期望值 |
| **电阻 200 Ω 档** | `Ω` 200 | 上电**前**测短路 | `3V3↔GND` 读数 **>100 Ω 正常**，接近 0 就是短路 |

**表笔怎么拿**：黑笔（COM）先固定在一个点上，红笔去点另一个点，**单手操作**，另一只手不要碰电路。测相邻两针时，两根表笔**不要并排戳**——2.54 mm 间距，一笔滑过去就是短路。

## 4. 认识零件（10 min 认针脚，认错就烧）

### 4.1 主控 ESP32-S3-DevKitC-1（N16R8）

**两个 USB 口，别搞混**：

| 口 | 外形 | 接到 | 用途 | 本手册用哪个 |
|---|---|---|---|---|
| 标 **UART** | Micro-USB | 板载 USB-UART 桥接芯片 | 烧录 + 串口监视器（兼容性最好） | 备用（Type-C 口认不到时用它） |
| 标 **USB** | **Type-C** | 芯片原生 USB（USB OTG / JTAG） | 烧录 + 原生串口 + JTAG | ✅ **主用这个**（手里是 Type-C 线） |

**要点**：

- **两个口不要同时插两根线供电**（官方明确：三种供电方式互斥，多路同时供电会反灌）。
- 排针**已焊好**（下单时选的"加焊排针"），可以直接插面包板或插杜邦线母头。
- **排针是 2×22（44 针）**。一侧（J1）的 **1、2 脚是 3V3**，同一侧的 **21 脚是 5V、22 脚是 GND** ——⚠️ **5V 与 GND 是紧挨着的两针**，取电时看错一格就是 5 V 进 3.3 V 器件。**接电源前先用万用表量一下准备用的那一针。**
- 板上电源脚只有两个方向：`5V`（来自 USB 的 VBUS）与 `3V3`（板载 LDO 输出）。**本工程所有模块一律从 `3V3` 取电。**
- **GPIO33–37 被 Octal PSRAM 占用**，**GPIO26–32 归 flash**，都不要接东西。本手册用到的 **GPIO4 / 10 / 11 / 12–17 全部安全**。
- 板上有 `BOOT` 与 `RST` 两个小按钮：烧录认不到口时，按住 BOOT → 点一下 RST → 松 BOOT，强制进下载模式。

### 4.2 屏：1.9" IPS ST7789 170×320（8 针）

针脚定义（**从有方焊盘/丝印圆点那一端开始数，第 1 针**）：

| 针 | 丝印 | 接到 | 说明 |
|---|---|---|---|
| 1 | **VCC** | 3V3 | **3.3 V，不许接 5V** |
| 2 | **GND** | GND | — |
| 3 | **DIN**（SDA/MOSI） | GPIO12 | 数据 |
| 4 | **CLK**（SCL/SCK） | GPIO13 | 时钟 |
| 5 | **CS** | GPIO14 | 片选 |
| 6 | **DC**（A0） | GPIO15 | 命令/数据选择 |
| 7 | **RST**（RES） | GPIO16 | 复位 |
| 8 | **BL**（LED/BLK） | 3V3（常亮）或 GPIO17 | ⚠️ **漏接 = 全黑，最常被误判成"屏坏了"** |

**两个必须知道的现象**：

- **插反了不会立刻烧**（3V3 与 GND 在第 1、2 针，反插等于电源反接）——但会发热，**上电 5 秒内摸到烫就立刻拔**。
- 170×320 是**非标准分辨率**，控制器内部分配是 240×320，**必须带 35 像素列偏移**。不设偏移的现象：画面整体右移 35 像素、左边一条花边。代码处理见 §5.4。

### 4.3 BME280 模块（GY-BME280-3.3，6 针）

| 针 | 接到 | 说明 |
|---|---|---|
| **VIN** | 3V3 | 3.3 V 版，**不许 5V** |
| **GND** | GND | — |
| **SCL** | **GPIO10** | I²C 时钟 |
| **SDA** | **GPIO11** | I²C 数据 |
| **CSB** | 3V3（或悬空） | 拉高 = I²C 模式；拉低会进 SPI 模式，扫不到地址 |
| **SDO** | 悬空 = **0x76**；接 3V3 = 0x77 | 地址选择 |

✅ **判据**：I²C 扫描必须打印 **0x76**。扫到 0x77 说明 SDO 接了 3V3（不影响使用，改代码地址即可）；**扫不到任何地址 = 接线错或模块是 5V 版**。

### 4.4 按键模块（3 针）

| 针 | 接到 | 说明 |
|---|---|---|
| **VCC** | 3V3 | 模块自带 10 kΩ 上拉 |
| **GND** | GND | — |
| **OUT / SIG** | **GPIO4** | 松开 = 高电平，按下 = 低电平 |

⚠️ **不许用 GPIO0**：那是 BOOT 拉低进下载模式的脚，开机瞬间误触会直接进烧录态，屏永远起不来。

### 4.5 面包板怎么用（新手最容易在这里白干一小时）

```
    ┌─────────────────────────────────────────┐
 +  │ ● ● ● ● ●  ● ● ● ● ●  ● ● ● ● ●  ● ... │  ← 上电源轨（红）
 -  │ ● ● ● ● ●  ● ● ● ● ●  ● ● ● ● ●  ● ... │  ← 上地轨（蓝/黑）
    ├─────────────────────────────────────────┤
    │ a ● ● ● ● ● │ ● ● ● ● ●                │
    │ b ● ● ● ● ● │ ● ● ● ● ●                │  ← 中缝：左右两半互不导通
    │ c ● ● ● ● ● │ ● ● ● ● ●                │
    │ …           │                          │
    ├─────────────────────────────────────────┤
 +  │ ● ● ● ● ●  ● ● ● ● ●  ● ● ● ● ●  ● ... │
 -  │ ● ● ● ● ●  ● ● ● ● ●  ● ● ● ● ●  ● ... │
    └─────────────────────────────────────────┘
```

三条规则：

1. **同一竖列的 5 个孔是通的**（a–b–c–d–e 为一组，f–g–h–i–j 为另一组），**跨中缝不通**。
2. **模块必须跨中缝插**——两侧引脚各落一边。不跨缝 = 左右两针短路，上电就烧。
3. **电源轨整条连通，但中间可能断开**（部分面包板红蓝线在中段断）。开工前用通断档从轨的最左测到最右，**响才算整条通**。

## 5. 阶段 A：免焊装配（60–90 min，全程不动烙铁）

> 这一段做完，整机就已经能演示了。焊接和装盒都是"更好看"，不是"能不能用"。

### 5.1 摆位（先摆后接，别边接边改）

```
┌──────────────────── 面包板 400 孔 ────────────────────┐
│                                                        │
│  [屏 8 针]        [ESP32-S3]         [BME280]  [按键]  │
│   跨中缝          跨中缝             跨中缝    跨中缝   │
│                                                        │
│  上轨：3V3（红）  下轨：GND（蓝）                       │
└────────────────────────────────────────────────────────┘
         ↑ 屏与主控之间留 2 列空位，方便手指插拔
```

**摆位原则**：主控放中间（两边都能出线）；屏放最左（排线短、朝向观众）；BME280 放最右（远离主控发热，温度读数才准）；按键放最右外沿（手指好按）。

### 5.2 接线表（模块 15 根 + 供电 2 根 = 17 根，逐根接、逐根划掉）

| 用途 | 颜色 |
|---|---|
| 3V3 | **红** |
| GND | **黑** |
| SCL / CLK | **黄** |
| SDA / DIN | **绿** |
| CS | 蓝 |
| DC | 白 |
| RST | 橙 |
| BL | 紫 |
| 按键 OUT | 灰 |

**屏（8 根）**

| # | 起点（屏） | 终点（主控/电源轨） | 线型 |
|---|---|---|---|
| P1 | VCC | 3V3 轨 | 公对母 |
| P2 | GND | GND 轨 | 公对母 |
| P3 | DIN | **GPIO12** | 公对母 |
| P4 | CLK | **GPIO13** | 公对母 |
| P5 | CS | **GPIO14** | 公对母 |
| P6 | DC | **GPIO15** | 公对母 |
| P7 | RST | **GPIO16** | 公对母 |
| P8 | BL | **3V3 轨**（常亮方案） | 公对母 |

**BME280（4 根）**

| # | 起点 | 终点 | 线型 |
|---|---|---|---|
| S1 | VIN | 3V3 轨 | 公对母 |
| S2 | GND | GND 轨 | 公对母 |

**按键（3 根）**

| # | 起点 | 终点 | 线型 |
|---|---|---|---|
| K1 | VCC | 3V3 轨 | 公对母 |
| K2 | GND | GND 轨 | 公对母 |
| K3 | OUT | **GPIO4** | 公对母 |

> 合计 **8 + 4 + 3 = 15 根**（屏、BME、按键到模块的线）。**此外主控自己还要 2 根**：`3V3 → 3V3 轨`、`GND → GND 轨`，**共 17 根**。
> 接完数一遍：**3V3 轨上应插 5 根**（主控、屏 VCC、屏 BL、BME VIN、按键 VCC），**GND 轨上应插 4 根**（主控、屏 GND、BME GND、按键 GND）。
> **很多人忘了给面包板电源轨"上电"**——主控不往轨上接线，轨就是死的，然后怀疑模块坏。

### 5.3 ✋ 上电前三次测量（每次都不到 1 分钟，能救一块板）

**断电状态下做**：

| 测什么 | 档位 | 合格 | 不合格说明 |
|---|---|---|---|
| `3V3 轨 ↔ GND 轨` | 电阻 200 Ω / 通断 | **不响，>100 Ω** | 响 = 短路，逐根拔线定位 |
| `5V 脚 ↔ 3V3 脚` | 通断 | 不响 | 响 = 电源串了，必烧 |
| 屏第 1、8 针是否插在同一侧 | 目视 | 跨中缝 | 不跨缝立刻重插 |

**插 USB 后**：

| 测什么 | 档位 | 合格 | 不合格说明 |
|---|---|---|---|
| 3V3 轨电压 | 直流 20 V | **3.25–3.35 V** | <3.2 V = LDO 过载或线太细 |
| 主控芯片温度 | 手指背轻碰 | **微温，不烫** | 烫 = 有短路，立刻拔 |
| 屏是否发热 | 手指背 | 不烫 | 烫 = 插反了 |

### 5.4 软件环境（一次性配置，30 min，D1 卡最久就在这）

**Arduino IDE 2.x 配置五步**：

1. **加开发板地址**：文件 → 首选项 → 附加开发板管理器网址，填
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
2. **装开发板包**：开发板管理器搜 `esp32`，装 **Espressif Systems 的 esp32（2.0.x 或 3.x 均可）**
3. **选板子**：工具 → 开发板 → **ESP32S3 Dev Module**
4. **四个必须改的选项**（默认值不对，会"烧进去但不跑"）：

| 选项 | 必须设成 | 不改的后果 |
|---|---|---|
| **Flash Size** | **16MB** | 默认 4MB，超过就烧不进去 |
| **PSRAM** | **OPI PSRAM** | N16R8 是 Octal PSRAM，设 Disabled 会开不了机 |
| **USB CDC On Boot** | 用 **Type-C（USB）口 → Enabled**；用 **Micro-USB（UART）口 → Disabled** | **设反了串口监视器一个字都没有**（输出被送去另一个口了） |
| **Upload Speed** | 921600（不稳定就降 460800） | 只是快慢问题 |

> **USB CDC 这条最容易白折腾**：它决定"printf 从哪个口出来"。Enable 后输出走 Type-C 原生口；Disable 后走 Micro-USB 桥接口。**你插哪个口，就按哪个口设。**

5. **选端口**：工具 → 端口 → 出现 `COMx` 的那个。**插拔一次看哪个端口消失/出现，就是它。**

> **端口不出现**：按住 `BOOT` → 点一下 `RST` → 松 `BOOT`，再插线。仍不出现就换 **UART（Micro-USB）口**，并装 CP210x 驱动。

**判线方法**（5 秒，避免"烧录无反应"）：把线插到手机上——**能传文件就是数据线，只能充电就不是**。

**屏驱动库**：装 `GFX Library for Arduino`（作者 moononournation）。它是唯一默认支持 170×320 + 35 偏移的常用库，能省掉"画面右移一条花边"这个坑。

### 5.5 D1 · 点亮屏（30–40 min，✅ 这是全部验收的地基）

**目标**：屏出现彩条/文字，背光均匀。

**最小示例（只做点亮验证，不做业务 UI）**：

```cpp
#include <Arduino_GFX_Library.h>

// ESP32-S3：DIN=12, CLK=13, CS=14, DC=15, RST=16
Arduino_DataBus *bus = new Arduino_ESP32SPI(15 /*DC*/, 14 /*CS*/, 13 /*SCLK*/, 12 /*MOSI*/, GFX_NOT_DEFINED /*MISO*/);
//                      rst  rot  ips   w    h    col_off1 row_off1 col_off2 row_off2
Arduino_GFX *gfx = new Arduino_ST7789(bus, 16, 1, true, 170, 320, 35, 0, 35, 0);

void setup() {
  gfx->begin(40000000);           // 40 MHz 先求稳，通了再往 80 MHz 试
  gfx->fillScreen(RED);   delay(500);
  gfx->fillScreen(GREEN); delay(500);
  gfx->fillScreen(BLUE);  delay(500);
  gfx->fillScreen(BLACK);
  gfx->setTextColor(WHITE);
  gfx->setTextSize(3);
  gfx->setCursor(20, 140);
  gfx->println("D1 OK");
}

void loop() {}
```

✅ **判据**（三条全中才算过）：

1. 红→绿→蓝→黑 四色依次刷满，**没有残留条纹**；
2. 屏上出现 `D1 OK`，**字是正的、不镜像**；
3. 背光**均匀**，四角不发暗、不闪。

**不亮 / 不对，按这个顺序查**（顺序就是概率从高到低）：

| 现象 | 先查 | 怎么确认 |
|---|---|---|
| **全黑，一点光都没有** | **BL 是否接了** | 最常见。把 BL 直接插到 3V3，屏应该出现"灰白光" |
| 全黑但有灰白光 | CS / DC 接反 | 对着 §5.2 表逐根核 |
| 全黑，BL 也接了 | RST 没接或接错 | RST 必须接 GPIO16，不能悬空 |
| 白屏 | 初始化没跑 | 串口是否有输出？波特率 115200 |
| 花屏 / 雪花 | SPI 线太长或接触不良 | 杜邦线换短的（10 cm 就够），重插一遍 |
| **画面右移 35 像素、左侧一条花边** | 缺列偏移 | 确认构造函数里两个 `35` 都在 |
| 颜色反相（红变青） | IPS 反色 | `begin()` 后加 `gfx->invertDisplay(true)` |
| 文字镜像 | 旋转方向错 | 把 `rot` 从 1 改成 3 |
| 烧录报错 | 端口/线 | 换 UART 口 + 按 BOOT 进下载模式 |

📷 **屏点亮那一刻拍照**，这是 D1 唯一的物证，报告里要用。

### 5.6 D2 · 读温湿压（10 min）

**目标**：串口打印 I²C 地址 **0x76**，并读出温度/湿度/气压三个数。

**接线确认**（错了必扫不到）：`SCL→GPIO10`、`SDA→GPIO11`。**这两个最容易反**——反了不会烧，只是扫不到，所以很多人以为模块坏了。

**扫描代码**：

```cpp
#include <Wire.h>
void setup() {
  Serial.begin(115200);
  Wire.begin(11, 10);            // ⚠️ 顺序是 (SDA, SCL) = (11, 10)
  delay(300);
  Serial.println("I2C scan...");
  for (uint8_t a = 1; a < 127; a++) {
    Wire.beginTransmission(a);
    if (Wire.endTransmission() == 0) { Serial.printf("found 0x%02X\n", a); }
  }
}
void loop() {}
```

✅ **判据**：

| 项 | 合格 |
|---|---|
| 扫描结果 | 打印 `found 0x76`（或 0x77） |
| 温度 | 与手机天气同量级（±5 ℃ 内可接受，模块自发热会偏高 1–2 ℃） |
| 湿度 | 20–90 %RH 合理区间 |
| 气压 | **1000–1030 hPa**（沈阳海拔约 45 m，落在这个区间） |

**扫不到，按顺序查**：

1. `Wire.begin(11, 10)` 顺序写反没有（SDA 在前）；
2. SCL/SDA 两根线是不是接反了（对调试一次，**断电再换**）；
3. VIN 是不是接了 3V3（接 5V 可能已经烧了，换模块试）；
4. 模块丝印是不是 **BMP280**（BMP280 没有湿度寄存器，扫描能过但读湿度报错）；
5. CSB 是否被误接 GND（拉低进 SPI 模式，I²C 不响应）。

### 5.7 D3 · 接按键（5 min）

**目标**：按一次打印一次，不抖、不自动触发。

```cpp
const int KEY = 4;             // ⚠️ 不许用 GPIO0
void setup() { Serial.begin(115200); pinMode(KEY, INPUT_PULLUP); }
void loop() {
  static int last = HIGH; static uint32_t t0 = 0;
  int v = digitalRead(KEY);
  if (v != last && millis() - t0 > 25) {        // 25 ms 消抖
    t0 = millis();
    if (v == LOW) Serial.println("PRESS");
    last = v;
  }
}
```

✅ **判据**：手指按 10 次，串口恰好 10 行 `PRESS`。**多行 = 没消抖；不响应 = OUT 没接 GPIO4。**

### 5.8 D4 · 改电池供电（5 min，✅ 答辩开场就是这一下）

**目标**：拔掉电脑那根线，屏继续亮 30 秒以上不重启。

**步骤**：

1. 两节电芯装进免焊套件。**看电池仓里的 `+` 标记对极性**——平头那端有凸环的是正极。
2. ⚠️ 装之前再测一次两节压差（§3.2 已测，装前复核 <0.10 V）。
3. 套件 **USB-A 母口** → **A-to-C 线** → S3 的 **Type-C 口**。
4. 先插套件侧、再插板上侧；**然后拔掉电脑那根线**。

✅ **判据**：

| 项 | 合格 |
|---|---|
| 拔线瞬间 | 屏**不闪、不黑** |
| 30 秒 | 屏**不重启**（没有重新出彩条） |
| 5V 输出实测 | **4.85–5.15 V**（低于 4.75 V 会掉压重启） |
| 连续运行 | 10 分钟不掉电 |

**三个必踩的坑**：

- **A-to-C 线**：套件是 USB-A 母口，**C-to-C 线插不进去**。手上没有就找一根旧安卓线。
- **套件可能没有开关**：把电芯装进去就通电。若脚本写"拨开关"，改成"插上 USB"。
- **升压掉压**：如果拔线后 3 秒黑屏，多半是电芯电压低或升压模块带不动屏（屏背光是耗电大户，峰值 100 mA+）。先换满电电芯试。

> **做到这一步，整机已经成立**，可以开始排练 90 秒演示脚本。焊接和装盒都是后面的加分项。

## 6. 阶段 B：焊接（60–120 min，✂ 可砍）

### 6.1 先决条件（四条不全，别插烙铁）

1. D1–D4 **全部 ✅**（焊完要和面包板行为完全一致，前提是面包板版本已完全正确）；
2. 有一块可以焊废的板子练手（用 Maker-ESP32 练，见 §6.7）；
3. 排母到位（见 §6.2）；
4. 窗户开着，或者至少有风扇往外吹。

### 6.2 一个必须先说清的事：本单没有排母

下单的 13 项里是 **1×20P 排针（公针，10 条）**，没有 **排母（母座）**。

- **排针**只能焊在洞洞板上**朝上**，让杜邦线的**母头**插上去；
- 要让"开发板能插拔"，洞洞板上必须焊 **排母**。

**三个选择，按推荐度**：

| 方案 | 做法 | 成本 | 适合 |
|---|---|---|---|
| **A（推荐）** | 补买 **2 条 1×22 排母**（板用）+ **1 条 1×8 排母**（屏用），2.54 mm | ¥3–4 | 想做成可插拔、可维修的成品 |
| **B** | 洞洞板只做"屏 + 按键 + BME280 的转接板"，主控继续用杜邦线 | ¥0 | 时间紧，只想把屏固定住 |
| **C** | 把开发板直接焊死在洞洞板上 | ¥0 | **不推荐**：一旦击穿，板和洞洞板一起废 |

> 开发板原厂排针是 **2×22（44 针）**，因此排母要买 **2 条 1×22**（屏用 **1 条 1×8**）。买之前拿尺子数一遍手上的板子，不同卖家版本偶有差异。

### 6.3 焊接工艺参数（照这张表做，焊点就合格）

| 参数 | 值 | 说明 |
|---|---|---|
| 烙铁温度 | **330 ℃（含铅锡）/ 350 ℃（无铅）** | 温度过高会掀铜箔，过低会虚焊 |
| 单点受热时间 | **2–3 秒**，**绝不超 5 秒** | 超时立刻停手，等冷却再补 |
| 焊锡丝 | 0.8 mm，含铅 Sn63/Pb37 优先 | 新手用无铅容易焊成"豆腐渣" |
| 助焊剂 | 每个焊点点一下，**不要多** | 多了要洗板，松香残留会发粘 |
| 锡量 | **小火山锥**，润湿角 <90°（像小斜坡，不是圆球） | 圆球 = 没润湿 = 虚焊 |
| 顺序 | **先低后高、先中间后四角、先小后大** | 焊高的会挡住矮的 |
| 姿势 | 烙铁头**同时接触焊盘和针脚**，送锡在**接触点**，不是烙铁头上 | 送在烙铁头上会烧掉助焊剂 |

**焊前 30 秒**：摸一下金属机箱/水管放静电；**不要穿化纤外套**；把袖子卷起来。

### 6.4 焊接顺序（七步）

| 步 | 内容 | 耗时 | 判据 |
|---|---|---|---|
| 1 | **练手**：拿 Maker-ESP32 的废针脚位焊 5 个点 | 10 min | 5 个点都是小火山锥，不连锡 |
| 2 | 洞洞板上**定位**：把排母插在开发板上，整体放到洞洞板上比位，用记号笔画四角 | 5 min | 四角都落在焊盘上，不压孔 |
| 3 | 先焊**排母的两端各 1 针**（固定），再检查是否歪 | 5 min | 排母与板边平行，不翘 |
| 4 | 焊完排母剩余针（**每焊 3 针停 10 秒**） | 20 min | 无连锡 |
| 5 | 焊屏的 8 针排母（1×8） | 10 min | 同上 |
| 6 | 焊按键 3 针（或焊 3 针排针接杜邦线） | 5 min | 同上 |
| 7 | 焊电源与地母线（用剪下的排针脚或细铜线沿板边走一条） | 15 min | 整条母线通断一致 |

> **技巧**：焊排母时**把排母插在开发板上一起焊**——开发板本身就是夹具，能保证针距不变形、不歪。焊完再拔下来。⚠️ 但**开发板此时必须断电、且不要用手捏住金属部分**。

### 6.5 焊后验通断（✋ 这一步不做，上电就是赌）

**先目视**（放大镜/手机微距拍照看）：

- [ ] 没有连锡（相邻两针之间没有锡桥）
- [ ] 没有虚焊（每个点都是斜坡锥，不是圆球）
- [ ] 没有拉尖（针脚上端没有锡刺）
- [ ] 没有焦痕（焊盘发黑 = 温度过高，铜箔可能已脱）

**再用万用表通断档逐点测**：

| # | 测什么 | 合格 |
|---|---|---|
| 1 | 每个焊点 ↔ 对应排母孔内壁 | **响**（证明焊透了） |
| 2 | 相邻两针之间 | **不响**（证明没连锡） |
| 3 | 3V3 母线 ↔ GND 母线 | **不响，>100 Ω** |
| 4 | 屏 8 针按 §5.2 表逐根对到排母对应孔 | 全部响 |
| 5 | 按键 OUT ↔ 排母第 3 孔 | 响 |
| 6 | 所有 GND 点互相之间 | 全响 |

### 6.6 五种焊缺陷与修补

| 缺陷 | 长什么样 | 后果 | 怎么补 |
|---|---|---|---|
| **虚焊** | 圆球状、表面发暗、锡没爬到焊盘上 | 时通时断，最坑 | 补助焊剂，烙铁压住 2 秒重新熔化 |
| **连锡** | 两针之间一条锡桥 | 短路，上电烧 | 加助焊剂，烙铁从桥中间往外带；或用吸锡带 |
| **拉尖** | 针脚顶端一个锡刺 | 可能扎穿相邻线皮 | 烙铁轻碰一下带走 |
| **冷焊** | 表面像砂纸、无光泽 | 接触电阻大，I²C 会随机掉 | 助焊剂 + 重焊 |
| **铜箔脱落** | 焊盘整块翘起 | 该点报废 | 用细导线"飞线"到最近的同网络焊盘 |

### 6.7 Plan B 练手（如果主控延误或击穿）

拿 **Maker-ESP32（已有）** 练焊接，注意三点：

1. 它是 **micro-USB**，烧录线跟 S3 的 Type-C 不通用；
2. 板上 4 路电机驱动 + 舵机 + 蜂鸣器 + RGB 已占用大量 GPIO，**要先测绘**哪些还空着（万用表蜂鸣档从模块引脚倒推）；
3. 真要走这条路，编译目标要从 `esp32s3` 改回 `esp32`，且**必须重跑端云对拍**（不能沿用 S3 的结论）。

## 7. 阶段 C：装盒（30 min，✂ 可砍）

### 7.1 布局（盒内 100×100×100，实际可用约 95×95×90）

```
        透明盖（屏贴内侧）
   ┌──────────────────────────┐
   │   ┌──────────────┐       │
   │   │  1.9" 屏     │       │  ← 双面胶贴盖内侧
   │   └──────────────┘       │
   │  ┌────────┐   ┌────────┐ │
   │  │ 主控   │   │ 电池   │ │  ← 两者隔 ≥5 mm
   │  └────────┘   └────────┘ │
   │  ┌────────────────────┐  │
   │  │ 面包板（背胶粘底） │  │
   │  └────────────────────┘  │
   └──────────────────────────┘
```

### 7.2 安装顺序

1. **屏贴盖内侧**：擦净盖内表面 → 3M 双面胶贴屏背四边 → 对准位置压实，**静置 10 分钟再翻面**。透明盖方案不需要开窗。
2. **面包板粘盒底**：撕背胶，居中偏下贴，**留出上方 15 mm 给屏的排线弯曲空间**。
3. **电池套件固定**：双面胶 + 扎带双保险，**与主控隔 5 mm 以上**（升压模块发热，且避免挤压杜邦线）。
4. **线束整理**：用扎带把 15 根线束成两股（信号一股、电源一股），**不要让线压在电芯上**。
5. 📷 **盖盖前拍一张接线全景照**——返工时全靠它，比回忆可靠。

### 7.3 ⚠️ IP67 的真相

盒子标 IP67，但**只要你开了一个孔，它就不再是 IP67**。本方案：

- **屏在透明盖内侧 → 不开窗**（这是当初选透明盖唯一的原因）；
- **电池线从盖缝引出** → 盖缝有密封圈，压紧后基本密封，但不建议淋雨；
- 若必须开孔（比如要外接探头），**开完用中性硅胶封死**，且答辩时不要宣称"防水"。

### 7.4 装盒后复测（四条，一条不过就拆开重装）

| # | 测什么 | 合格 |
|---|---|---|
| 1 | 装盒后上电 | 屏正常显示，无花屏 |
| 2 | 摇一摇盒子 | 无零件晃动声（有 = 没固定好） |
| 3 | 连续运行 10 min | 屏不闪、不重启 |
| 4 | 手摸盒内电池区 | 不烫（微温正常） |

## 9. 故障速查（21 条，按"症状"查）

| # | 症状 | 最可能原因 | 一次测量就能定性 | 处理 |
|---|---|---|---|---|
