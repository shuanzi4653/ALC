## 一、改法（四条原则，后面谁改都照这个）

1. **只陈述事实与数字**，不写"这说明 / 恰好 / 不是X而是Y"这类自我辩解。
2. **同一事实不在同一行里说三遍**（站数原来在一行里出现了三次）。
3. **解释性长句搬进 `title`**，屏面只留短句。
4. 分隔统一用 `·`，不用破折号串；数字带单位。

## 三、两处顺手修的探针坑（都记在案）

**① 滑块 `disabled` 时设值 = 什么都不会发生。**
第一版快照脚本在"建场还没完成"时就把滑块设到 max，`input` 当时是 `disabled`，于是读到的是 T+00 —— 看起来像"文案没改对"，实际是**量具早了一步**。
正确做法：先等 `!e.disabled` 再设值（`snap_t6.py` 就是这么做的）。
**通用规则：判据要等被测对象进入可交互状态。**

**② 旧串判据必须查"两个包"。**
反事实相关文案在独立 chunk（`CounterfactualPanel-*.js`）里，只 grep `index-*.js` 会得出"没改到"的错误结论。
