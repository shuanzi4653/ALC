## 2. 已修好的视觉缺陷（12:50 结案，根因不是缩放）

**右下「气象实况」列表在画面上不可见 → 已修好。**

最终根因（一句话）：`section.operations-console` 在 `national` 视图下仍被渲染成一个
**空壳卡片**（innerText 为空，却有 `min-height:480px` 和不透明底 `#0e1c2b`），
它排在 `.traffic-page` 之后，正好盖住后者的溢出区。

失效链条：

1. `.traffic-page` 的盒子被压到 210 px，而它的内容 `.nlx` 实际 661 px（溢出可见）；
2. `.wb-body` 的下一个兄弟 `.operations-console` 从 y=270 起画了一张 480 px 高的空卡；
3. 气象列表位于 y=374–634 —— 整段落在空卡底下，DOM/尺寸/文字全都正常，所以怎么量都对。

判据（一条命令定性，别再量尺寸）：

```js
document.elementFromPoint(article.getBoundingClientRect().centerX, centerY)
// 修前 → SECTION.operations-console（别人的卡片盖住了）
// 修后 → ARTICLE
```

修法：`TrafficWorkbench.vue` 里 `<OperationsConsole>` 的 `v-if` 排除列表加 `'national'`。

**已排除的错误假设**（下面这些都不是原因，别再回头查）：
flex 收缩、高度塌陷、样式未生效、引导浮层遮挡、headless/合成层、祖先 `transform: scale` 裁剪。

下面这段是当时的原始记录，保留作对照，**结论已在上面被推翻**：

**右下「气象实况」列表在画面上不可见。**

已确证的事实（不要再重复测量）：

```
.nlx-wx        offsetHeight = 260，computed height = 260px，flex = 0 0 auto
.nlx-wx-scroll offsetHeight = 205（改 block+200px 后亦然）
article        18 条，首条 offsetHeight = 55，innerText = "沈阳 ZYTX 7°C · 能见 — · 风 —"
```

即 **DOM、文本、尺寸全部正常，但截图里该区域是空白**。已排除：
- flex 收缩（已改 `flex:none` / `flex:0 0 auto` / 外层改 `display:block`）
- 高度塌陷（实测 260 / 205）
- 样式未生效（computed 值正确）
- 引导浮层遮挡（已修，且修后仍空白）
- 元素截图错位（整页截图同样空白）

**下一步唯一正确的诊断路径**（别再盲改 CSS）：
1. 用**真实浏览器窗口**（非 headless）打开 `http://127.0.0.1:5180/#/situation/national`，肉眼确认是否同样空白。
   - 正常 → 是 headless/合成层截图问题，代码不用改，记录结论即可。

2. 在真实窗口按 F12：

## 4. 环境备忘（踩过的坑，直接照做）

- pip 必须 `-i https://mirrors.aliyun.com/pypi/simple/`；`cryptography` 不在 requirements，要单装。
- pytest 必须加 `--basetemp=../.run/pytest-tmp`，否则 `%TEMP%\pytest-of-*` 拒写，60 条用例直接 ERROR。
- 全量 `pytest` 单进程会跑到 shapely 并集超时（>10 min），按文件拆开跑；`test_radar_avoidance` 单独 34/34、45 秒。
- `dev.ps1` 会因 `HTTPS_PROXY`/`https_proxy` 重复键在启动 Python 时失败：先 `Remove-Item Env:https_proxy`。
- 网关需 `--python-service.base-url=http://127.0.0.1:8600`（或存在 `config/application.yml`，从 example 复制）。
- 手工起全套：
  ```
  python -m uvicorn main:app --host 127.0.0.1 --port 8600
  java -cp "target/classes;$(cat ../.run/java-classpath.txt)" com.tianchuang.TianchuangApplication --server.port=8085 --python-service.base-url=http://127.0.0.1:8600
  npx vite --port 5180 --strictPort
  ```
- 截图用 `playwright-cli`，浏览器只能 `--browser=msedge`（本机没装 Chrome）；会话在命令结束后会被回收，**open+操作必须写在同一条 bash 里**。
