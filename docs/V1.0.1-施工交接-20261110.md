## 4. 环境备忘（踩过的坑，直接照做）

- pip 必须 `-i https://mirrors.aliyun.com/pypi/simple/`；`cryptography` 不在 requirements，要单装。
- pytest 必须加 `--basetemp=../.run/pytest-tmp`，否则 `%TEMP%\pytest-of-*` 拒写，60 条用例直接 ERROR。
- 全量 `pytest` 单进程会跑到 shapely 并集超时（>10 min），按文件拆开跑；`test_radar_avoidance` 单独 34/34、45 秒。
- `dev.ps1` 会因 `HTTPS_PROXY`/`https_proxy` 重复键在启动 Python 时失败：先 `Remove-Item Env:https_proxy`。
- 网关需 `--python-service.base-url=http://127.0.0.1:8600`（或存在 `config/application.yml`，从 example 复制）。
- 手工起全套：
  ```
  python -m uvicorn main:app --host 127.0.0.1 --port 8600
  java -cp "target/classes;$(cat ../.run/java-classpath.txt)" com.tianchuang.TianchuangApplication --server.port=8085 --python-service.base-url=http://127.0.0.1:8600
  npx vite --port 5180 --strictPort
  ```
- 截图用 `playwright-cli`，浏览器只能 `--browser=msedge`（本机没装 Chrome）；会话在命令结束后会被回收，**open+操作必须写在同一条 bash 里**。
