## 二、W-A：只改了两行，但两行都必须改

复测报告的根因判断准确，方案的工时估计偏大（说 2 小时、三层）。实情：

```python
# ① 汇总用的还是 T+00 那 53 条（上层 field() 已经按 minute 取了帧，这里没用）
snapshot = corridors(limit=None, case_id=case_id, minute=minute)   # ← 补 minute

# ② timeBase 取 describe() 的常量，所以顶栏时间基准也不跟
'timeBase': ((snapshot['observation'] or {}).get('observedAt')
             or (traffic_cases.describe(case_id).get('timeBase') if case_id else None))
```

其余全都不用动：`conclusion` 的 `31%` / `19 条`、`corridors.high/watch`、`kpiDetail` **都是从 `items` 派生的**，喂对帧就一起对。方案说的"别写第二套聚合"是对的 —— 我们本来就只有一套，只是喂错了帧。

**第 2 层（前端传 minute）上一轮 W-1 就已经做了**（`SituationBrief.vue:48`、`OperationsConsole.vue:73`），所以这一条实际工时约 **40 分钟**。

### 为什么这个 bug 会漏过去

W-1 我改的是 `corridor()` / `corridors()` 的签名与观测取数入口，两条都测了；`overview` 是**第三个调用方**，它内部那次调用不在我的改动清单里。教训：**给函数加参数时，要 grep 出所有调用点，而不是只改自己正在看的那一处。**

## 三、W-B 与方案的一处偏离（有意）

方案甲是「进入复盘页时用 `replace` 补 `?case=fog-20250105`」。我改成**只在页内默认**，不改 URL：

| | 方案甲（改 URL） | 实际做法（页内默认） |
|---|---|---|
| 副作用 | **全局** —— 首页/走廊/气象页一起切到案例态 | 只影响这一页的请求 |
| 风险 | 要动 `applyHash`/`pushState` 这套刚修好的路由 | 不碰路由 |
| 读者知情 | 靠顶部案例条（依赖全局态） | 页内明写「本页未指定案例，默认按…重放」+ 副标题标「气象快照 · 2025-01-05 沈阳大雾」 |

方案乙（实时态醒目提示）照做，并且做成了**可切换**：提示条上一个按钮，两种口径互切。这样答辩时既有"默认 2613 对 0"，也有"实时气象下就是 0，恰好证明系统没硬造风险"这条更硬的答法。

`?case` 存在时**不出现任何提示**（不重复打扰）。

## 四、W-D：方案给的定位是错的

方案写「后端 grep 应只剩 1 处，前端只剩检验结论表头 1 处」。实际**前端 0 处，后端 5 处**（第 5 处是方案和报告都漏掉的）：

| 行 | 原文 → 现文 |
|---|---|
| `v2.py:1371` | `低能见度 <1000 m（禁飞级）` → `（不可飞）`（**这处在后端，不在前端**） |
| `v2.py:1056` | `…与禁飞级判定均未参与本次计划` → `…与观测档判定均未参与本次计划` |
| `v2.py:1440` | `走廊当前观测已达禁飞级` → `…已达不可飞档` |
| `v2.py:1650` | `A 组有 %d 架次会飞进禁飞级走廊` → `…飞进不可飞走廊` |

顺带统一了两处"混成词"：`不可飞级` 这种写法也不该有（"级"是旧口径残留），一律用 `不可飞` / `需谨慎` + `停飞档` / `谨慎档`。
`cases.py` 的 `why` 数据串与 `nowcast.py` 的阈值 docstring 也一并改；源码里剩下的 `禁飞级` 只在 `#` 注释里作为历史说明保留。

**没有改前端任何一处** —— 因为前端本来就干净。按方案分工做会白跑一趟前端。

## 七、没做的（维持评估，附理由）

| 项 | 为什么不做 |
|---|---|
| **1366×768 字号（F-10）** | 复测报告记的"已修"是量错了属性（量 `body` 的 CSS `zoom`，恒 1）。真实的 `.hstage` `transform: scale()` 在 1366×768 下是 **0.5028**、最小字 9.5 px，**这条仍然开着**。改它要动舞台逻辑高度 1080 → 960，牵动全部版面，且溢出是 `overflow:hidden` 静默裁掉、测试不会红。赛前不动，赛后单开一轮 + 四分辨率回归。 |
| `实测 N 站` 口径（P2-1） | 文案级，改错风险大于收益（方案判断正确）。 |
| 内存指标（P2-3） | 内存 523 → 215 MB 已稳定，且采集方式要先定（进程内 psutil vs exporter）。 |
| 滑块位置进 URL | 会动深链接逻辑，赛前风险 > 收益。 |
| `?minute=` 361–480 clamp | 滑块已不让拖过去，接口侧无人触碰。 |
