## 三、G-6 的施工边界（先划死，免得越改越宽）

| 允许动 | 不允许动 |
|---|---|
| `_slim_session` 里 `flights` 的 `points` | `mapFlights` 的字段与点数（地图靠它画） |
| 前端把**地图用**的数组换成 `mapFlights` | 统计口径（`groupAlerts` / `batchClearanceRows` 仍吃全量 `flights`） |
| 选中班次走 `/traffic/flight/{id}` 补取（已有） | `sessionId` / `stats` / `flightStats` |

**验收即回滚信号**（任一不满足就执行 R1）：

1. 地图上航线数量与改前一致（不得少）；
2. 点选任一班次，轨迹与「跟随航班」可用；
3. 处置台的「停止放行 N 班」「事件数」与改前同值；
4. `session` 体积 < 800 KB，且 `mapFlights[0].points` 仍在。

## 四、雾区优化与像素差分的验收线

- 差分：开/关「低能见度（雾·示意）」，**地图区 y∈[480,880] 变化像素 > 3000**；
  关掉时 <200 才算干净（图例行自身的 110 px 是噪声，不计）。
- 观感：圈不得盖住航线（layer 顺序在 `traffic-airspace` 之下）、不得压住城市标签；
  全域视图下能数出 4 个圈，沈阳那个最深。
