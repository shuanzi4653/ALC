# 模型、数据来源与实现边界

## 来源分离

| 数据 | 用途 | 来源及限制 |
|---|---|---|
| 三省行政边界 | 地图和米制裁剪 | 从既有china.json提取；保留SHA版本；素材授权与精度在公开发布前复核 |
| 中国境内站点目录 | 真实站号、名称和坐标 | [NOAA ISD目录](https://www.ncei.noaa.gov/pub/data/noaa/isd-history.csv)，按省界筛选，保存下载时间和原文件SHA256 |
| 三省历史观测 | 2025-07-01台账 | 沈阳54342099999、龙嘉54161099999、哈尔滨50953099999，共48条；各省JSON保存原链接和哈希 |
| 雨雷单体与风场 | 推演与实验 | SIMULATION / SIMULATED_CELL / SIMULATED_GRID，不是站网实况 |
| 原监测点 | 兼容已有监测 | live/sim/degraded独立标识，不能替代区域空间预报 |

[NOAA产品说明](https://www.ncei.noaa.gov/products/land-based-station/integrated-surface-database)介绍该数据集包含不同时段累计降水。归一化同时保留累计量和时段，不把24小时累计量当成瞬时mm/h。WND、TMP、VIS、AA1保留原质控字符串；保守接收质控码1/5，缺测或不合格字段为null。无雷暴概率来源则保持缺测。

每省独立读取缓存，一个省损坏仅该省ERROR。历史台账不驱动模拟规划器，不自动升级为真实空间预报。完整目录在 `backend-python/data/stations/catalog.json`，下载器为 `data_sources.py`。

## 连续模型与风险

保存带时区时间原点、种子和出生编号；每100分钟出现下一批单体，寿命150分钟。位置使用变化速度的积分，强度与形状连续变化，不按12小时取模重置。当前是确定性参数模型，无训练过程。

全域272个规则风场点，任务附近6.5km采样加密；符号将气象来向转换成地图去向。动态单体中心不伪装为固定站点。晴好和静风不制造雨雷区域；未知数据遮罩并撤下可飞路线。

阈值读取 `config/rules-v1.json`，与既有规则共用；规则内容哈希进入模型版本。BAN/CAUTION由气象单体加运行安全距离和情景缓冲推导，使用独立几何而非复制天气多边形。地图和规划器共用任务缓冲值。省界按Polygon/MultiPolygon处理，距离和缓冲在当地等距投影中以米计算。

## 路线

限定所选省份与最长180分钟时域，候选图包括端点、未来风险外侧点、左右辅助点。按经过时刻搜索左绕、右绕和延后20分钟。固定地速、单程、到达后作业时间来自显式参数。风场参与气象风险，不声称实现实测标定的风致能耗模型。

每条边必须完全在省界内，并避开该时间区间的风险扫掠体；一分钟采样加1080米保守运动/形变包络。到达后的作业时间也检查终点风险。方法偏保守，可能关闭实际存在通道的任务；有限候选图无解不是连续空间全局无解。

绕行用未取整时间：恰好3600秒保留，超过关闭；续航和期限独立检查。端点越界、数据未知、超时不放行。输出坐标首尾严格使用输入，动画按各拐点到达时刻计算位置。

## 证据、AI与重放

应用运行5个确定性取证工具；DeepSeek选择任务、天气、候选、决定和规则的证据ID，界面只显示冻结事实。AI不能改变几何或约束；坏引用、超时、限流、欠费、密钥失效均明确降级。自由文本创建任务和通用自主工具规划不是当前能力。

SQLite保存输入、版本、引擎指纹、候选、证据和解释轨迹。重放比较全部候选字段，模型或边界身份不同则报告不兼容并保留原记录。断网不影响几何重放。

## 不确定性和学习裁剪

800米缓冲与0米对照，三省各5个种子共30组敏感性结果在 `evaluation-v1/sensitivity.csv`。这是有限情景敏感性，不是概率、置信区间或真实误差界。

48条单日点观测不含区域雷暴真值、航迹结果或独立训练/验证/测试切分，未通过学习数据闸门。因此不训练或宣传XGBoost/ONNX增强，保留规则与合成基线。不报告未经实测的业务收益、用户访谈结论或飞行安全认证。
