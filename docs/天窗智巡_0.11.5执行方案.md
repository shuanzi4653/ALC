### W-25a · 处置台的"与天气无关"必须改成"范围声明"（1h）

#### 现在是什么

处置台（雾天）第一屏，原样：

```
361 个事件 / 涉及 3623 班 · 停止放行 123 班
停止放行 123 班，其中气象成因 0 班 —— 不要把这一屏读成天气造成的
气象成因 0        非气象成因 361
当前窗口内的 361 个事件里没有气象成因的：停止放行 123 班全部来自排程越界（超出推演时段），
与天气无关。切到「排程冲突」可查看这些事件。
```

三处问题（都在源码 `index.js` 约 205,090–205,120 字符处）：

```js
` 当前窗口内的 ` + h.value.total + ` 个事件里没有气象成因的：停止放行 ` + h.value.closedFlights +
` 班全部来自排程越界（超出推演时段），与天气无关。切到「排程冲突」可查看这些事件。 `
```

1. **"与天气无关"** —— 直接否定首页的 21 条禁飞；
2. **"切到「排程冲突」"** —— 全站没有这个 tab（`document.querySelectorAll('button')` 里没有文本为"排程冲突"的按钮），**"排程冲突"是卡片上的二分类标签**；
3. **没有给出"那天气去哪了"的出口**。

#### 改成什么

同一位置，改成三段（**纯文案 + 一个链接，不动任何数据**）：

```
当前窗口内的 361 个事件全部是排程类（超出推演时段 / 资源不足），
停止放行 123 班由此产生。

本案例（2025-01-05 沈阳大雾）只回放观测与判据，不重跑调度 ——
所以这 123 班与天气无关，这是范围声明的结果，不是天气没有进来。

天气进入决策的效果在「复盘 · 反事实对照」 →
```

那个 `→` 是一个按钮，点击执行 `navigate('counterfactual')`。

#### 为什么

- 现在这句话是**在自证清白**，读者只会记住"天气无关"四个字；
- 改成"范围声明"之后，同一件事变成**"我知道我的边界在哪，并且我把验证放在另一页"**——这是加分句，不是减分句；
- 顺手消掉一个指向不存在 tab 的死指引（评委点不到会认为是 bug）。

#### 怎么算改完（可断言）

```js
// 断言 1：页面内不存在"与天气无关"这 4 个字
assert(!document.body.innerText.includes('与天气无关'))
// 断言 2：不存在"切到「排程冲突」"
assert(!document.body.innerText.includes('排程冲突」可查看'))
// 断言 3：存在跳转按钮，且点击后页头出现「反事实对照」
document.querySelector('[data-go="counterfactual"]').click()
assert(document.body.innerText.includes('反事实对照 同一份计划'))
```

### W-25b · 雾天案例真的改一次调度（6h）—— 0.11.3 起未做完的那张

#### 现在是什么

`POST /api/traffic/session?scenario=live` **不带 case**（实测：响应 25.8 MB，`planRevision: traffic-plan-v1.3`，456 个字段里没有 case 相关字段）。所有调度数字来自实时推演：

- `运行事件 361 个 · 停止放行 123 班`（雾天与实时完全相同）
- 处置台 `气象成因 0`
- 台账首行 `CAR-1-01-1-05-0-0 已到达`

#### 改成什么

**一个参数、一处判断、一条断言。**

① 建场入口接受 `case`：

```python
# backend-python/app/traffic/session.py
@router.post('/session')
def build_session(scenario: str = 'live', case: str | None = None, ...):
    ctx = resolve_context(scenario=scenario, case=case)   # 与 v2/overview 用同一个函数
    plan = simulate(ctx)                                   # 内部按 ctx.observation 判禁飞
    return {'status': 'READY', 'case': ctx.case_id, 'stats': plan.stats, ...}
```

② `simulate()` 里唯一的改动：**「关闭」的成因判定里，加一条观测档优先**：

```python
reason = 'WEATHER_OBSERVATION' if obs_below_threshold else sched_reason
```

③ 前端：`?case=` 时把 `case` 传给 session；`BUILDING` 轮询结束前不渲染任何数字（现在首屏会显示"结论已作废"，见 W-31）。

#### 为什么

**这是 0.11.3 报告里的 P0-1，也是 0.11.4 报告里的 P0-A 的根。** 只改文案（W-25a）能让"打脸"变成"范围声明"，但评委只要问一句"那把你的天气关掉，结果会变吗"——**现在的答案是"不会"**。

改成真的会变之后，你们就有一条完整的因果链：

> 能见度 998 m → 21 条走廊达禁飞级 → 123 班中 X 班因天气停止放行 → 反事实显示"若不用观测档，这 X 班将暴露"

**这一条是从 76 分到 82 分的唯一路径。**

#### 怎么算改完（可断言）

```python
# 用同一 workspace，对比两个 case 的 stats
live = post('/api/traffic/session', params={'scenario': 'live'}).json()['stats']
fog  = post('/api/traffic/session', params={'scenario': 'live', 'case': 'fog-20250105'}).json()['stats']

assert fog['weatherClosed'] > 0,            '雾天必须有气象成因的停止放行'
assert fog['weatherClosed'] != live['weatherClosed'], '两个 case 的调度结果必须不同'
assert fog['planId'] != live['planId'],      '不能复用同一份计划'
# 前端
assert page_text('?case=fog-20250105', view='alerts').find('气象成因')['value'] > 0
```

**如果 6 小时做不完**：不要做。做一半会出现"计划改了、反事实没跟上"的第三种矛盾。**停在 W-25a 是安全的。**

### W-26 · 反事实明细表重排 + 删旧句（2h）

#### 现在是什么

- 顶部：`AI 改判 3048 架次（观测档 3048 · 概率档 0）`、`用 绕飞 3016 架次、延误 32 架次（1280 分钟），换掉 3016 架次的风险暴露`
- 明细表（`改判明细（最多 20 条）`）前 20 行：`规则 0 / 融合后 0 / 理由 低置信转人工复核`
- 页脚旧句：`延期后的风险未重算（本版本没有逐时概率），因此延期不会被判成降险手段`

第三处与走廊剖面的 00:00–06:00 逐时曲线直接冲突。

#### 改成什么

① **排序**：明细表先按 `fusedLevel - ruleLevel` 降序，再按 `p` 降序，只保留**等级实际变化的行**（`fusedLevel !== ruleLevel`）；确实不足 20 条时才补 `0→0` 的行，且这些行的"理由"列改成 `低置信留痕（未改判）`。

```js
const sample = rows
  .filter(r => r.fusedLevel !== r.ruleLevel)
  .sort((a, b) => (b.fusedLevel - b.ruleLevel) - (a.fusedLevel - a.ruleLevel) || b.p - a.p)
  .slice(0, 20)
```

② **表头改名**：`改判明细（最多 20 条）` → `改判明细 · 仅列等级发生变化的班次（最多 20 条）`；下面补一行小字：`本案例共 3048 班被改判为更严档，其中 3016 班为"概率档 → 观测档"。`

③ **页脚旧句删掉**，改成：

```
本快照只重放一次裁决（同一份计划、同一份气象），不重算延期后的时段风险；
逐时风险见「走廊剖面」的 0–6 h 曲线。
```

#### 为什么

现在这一页的结构是"**上面一个漂亮的因果，下面一张什么都没改的表**"。评委往下滚 800px 就会看到。改成"只列变了的"之后，表格与结论同向，而且**表格本身就是证据**。

#### 怎么算改完

```js
const rows = [...document.querySelectorAll('.cf table tbody tr')]
assert(rows.length > 0)
assert(rows.every(r => r.children[4].textContent !== r.children[5].textContent),
       '每一行的规则等级与融合后等级必须不同')
assert(!document.body.innerText.includes('本版本没有逐时概率'))
```

### W-29 · 字号下限 + 投影模式真放大（1h）

#### 现在是什么

- 全站最小字号 **9px**（首页 3 处、气象监测、民航情报）；`<12px` 节点：首页 336、民航情报 202、口径页 186。
- 投影模式：`<12px` 节点从 46 → 1（**确实生效**），但**最小字号只从 9 → 10px**，正文 13px 不变。

投影到 100 寸屏幕上，10px 与 9px 没有区别。

#### 改成什么

① `:root` 加一个字号阶梯，**禁止任何 `font-size` 低于 11px**：

```css
:root { --fs-min: 11px; --fs-body: 13px; --fs-title: 20px; }
[data-px] { font-size: var(--fs-min) !important; }   /* 所有 9/9.5/10px 的类改用它 */
```

② 投影模式（`body.projecting`）把正文整体放大：


### W-30 · 消融表标注"不可比"（2h）

#### 现在是什么

| 组 | A（关 AI）暴露 | B（开 AI）暴露 | 改判 | 延误 |
|---|---:|---:|---:|---:|
| none | 3016 | 0 | 3048 | 1280 min |
| obs | **0** | 0 | — | — |
| prob | 3016 | 0 | 3048 | 1280 min |
| loss | **0** | 0 | — | **121920 min** |

`obs` 与 `loss` 两组的 A 组暴露都是 0，`prob` 与 none 完全相同。**四组的"差值"里只有一组有意义。**

#### 改成什么

表格加第 4 列 `可比性`：

| 消融项 | A 暴露 | B 暴露 | 差值 | 可比性 |
|---|---:|---:|---:|---|
| 完整系统 | 3016 | 0 | −3016 | 基准 |
| 去掉概率档 | 3016 | 0 | −3016 | 与基准相同：**概率档在本案例上不改变结论**（诚实结论，别藏） |
| 去掉观测档 | 0 | 0 | 0 | **不可比**：A 组已无暴露 |
| 去掉期望损失 | 0 | 0 | 0 | **不可比**；但延误从 1280 → 121920 分钟（×95） |

再加一行脚注：

> "不可比"不是缺陷，是这个案例的性质：观测档一旦拿掉，A 组就再也进不了禁飞走廊，差值自然为 0。**要比，得换一个 A 组能暴露的案例。**

#### 为什么

答辩时"去掉 A 掉 2 分"这种表最有说服力，但**前提是每行都可比**。现在这张表会让评委问"去掉观测档怎么反而变成 0 了"——**一旦被问到，你就要在台上解释三分钟统计口径**。

**主动标"不可比"，比被问出来强十倍。**

#### 怎么算改完

表里 4 行的"可比性"列都有文字；`不可比` 的行旁边有解释；`prob` 一行出现"与基准相同"字样。

### W-31 · 建场体积与接口 422（8h，演示兜底）

#### 现在是什么

| 现象 | 实测 |
|---|---|
| `GET /api/traffic/session?scenario=live` 单次响应 | **25,831,200 B（24.6 MB）**，耗时 **42.65 s** |
| 首屏等待期间 | 页面显示"**正在按「公开天气驱动」重算…**" + "**结论已作废，等待新情景算完**" |
| `/api/traffic/operations` | **422（不带任何参数也 422）** |
| `/api/traffic/journal` | **422** |
| `?offline=1` | 39 个请求全成功，横幅与 KPI 正常（✅ 这条没问题） |

#### 改成什么

① **`session` 拆两段**：`/session` 只返回 `{status, progress, sessionId}`（现在就是这么返回的，115 B）；**计划本体走 `/session/{id}/plan` 分页拉**（每页 500 班，约 50 页），首屏只需要 `stats` + `kpis`。

② **首屏文案改掉"作废"**：

```
正在按「公开天气驱动」重算…（约 20 秒）
旧结论已收起，算完自动显示 —— 这不是故障。
```

③ 录一段 **2 分 30 秒的完整演示视频**（雾天动线：首页 → 走廊剖面判据表 → 处置台 → 反事实 → 分歧台账），现场循环播放兜底。**这一条比上面两条都重要**：现场网络 + 42 秒建场 + 外网底图，三个风险叠在一起。

#### 为什么

`25.8 MB / 42 s` 不是 bug，是结构问题；但**现场没有第二次机会**。录屏是最便宜的保险。

#### 怎么算改完

```python
t0 = time.time(); r = get('/api/traffic/session?scenario=live')
assert len(r.content) < 2000, 'session 响应必须 < 2KB'
assert time.time() - t0 < 1, 'session 必须立即返回'
p = get(f'/api/traffic/session/{sid}/plan?page=1')
assert p.status == 200 and len(p.json()['flights']) == 500
```
